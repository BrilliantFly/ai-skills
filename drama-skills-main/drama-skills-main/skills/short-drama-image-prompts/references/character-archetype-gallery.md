# 典型人物形象原型库（按风格包，供参考板直填）

> 配合 [character-reference-board.md](character-reference-board.md) 影棚模特卡三段式使用。
> 原型管"像什么"、style-packs.md 造型指引管"禁什么"、人物条目锚点管"这张脸"。
> 原型只负责年代形象，不负责面部（面部永远取 `视觉设定.md` 识别锚点）。

## 0. 分类维度（五维标签，选型入口）

每个原型带五维标签，按需过滤：

| 维度 | 取值 |
|------|------|
| **年龄段** | 儿童(6-12) / 少年(13-17) / 青年(18-35) / 中年(36-55) / 老年(56+) |
| **职业/阶层** | 学生 / 工人 / 公务·纪律 / 商界 / 江湖 / 家政·市井 / 无业·边缘 |
| **性格气质** | 张扬 / 温润 / 阴鸷 / 戆直 / 精明 / 沧桑 / 天真 |
| **阵营** | 正派 / 反派 / 灰色 / 功能（长辈、路人、群像） |
| **性别** | 默认给出代表性写法，跨性别时保持年代元素不变、换发型服装细节 |

**选型流程**：五维过滤 → 匹配风格包 → 无命中原型时按「正反派变体规则」从最近原型推导。

## 0.5 阵营与性格改编规则（同一底型的正/反派变体）

年代元素锁死不变，只调五处：

| 调整位 | 正派版 | 反派版 |
|--------|--------|--------|
| 面部细节 | 眉眼舒展、目光平视、面相端正 | 三白眼/吊梢眉、法令纹深、目光斜视 |
| 妆容肤质 | 净面、肤色匀净 | 面色暗沉、T区油光、眼下青黑 |
| 服装状态 | 整洁版：扣子扣齐、衣料平整 | 潦草版：领口歪斜、衣料起皱污渍、配饰过量 |
| 色彩倾向 | 取包内明亮高位色（色盘占比较大的浅色） | 取包内深色低位色（色盘末位的黑/深蓝/暗红） |
| 表情板五格 | 平静/微笑/坚定/难过/惊讶 | 阴沉/假笑/暴怒/冷笑/阴鸷 |

灰色角色 = 正派底型 + 一处反派元素（如整洁服装 + 三白眼）。

## 0.8 通用年龄族谱（跨包适配要点）

- **儿童**：圆脸比例、服装按包缩小一码（校服/开裆裤年龄上限守年代）、不化妆；禁成熟穿搭
- **少年**：校服或家庭便装为主、发型简单（平头/马尾）、配饰最少
- **青年**：原型库主力段，直接用各包条目
- **中年**：加岁月元素——发际线后移/白发掺半、皱纹与法令纹、体态微发福或消瘦；服装同原型"整洁版"
- **老年**：白发/盘发、老花镜、拐杖类道具；皱纹写实不磨皮；服色转包内中间调（不穿正派高位亮色）
- **群像/路人**：从对应包原型"降饱和"使用——去掉标志性配饰，只留年代服装底
