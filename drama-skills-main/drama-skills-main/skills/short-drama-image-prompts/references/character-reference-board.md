# 角色参考板（影棚模特卡三段式）

人物主资产的**默认出图排版**：一张横向构图参考板同时交付「主视图特写 + 三视图转面 + 表情板」，
供 downstream 分镜冻结关键帧、视频首帧和换脸/一致性工具（如 inswapper + insightface）取材。

> 本配方是 [人物与造型](character-and-look.md) 的**板式默认**；身份锚点、Look、连续性锁仍按该文档规则提取。
> 创作者点名其他板式（单图身份板、服装 Look 板等）时以创作者为准。

## 1. 板式结构（横向构图，4K/8K 超精细）

```text
┌────────────────────────────────────────────────────────────┐
│  左侧（约占1/2宽）          │  右上                          │
│  主视图：头肩特写美妆/身份肖像 │  三视图：正面·侧面·背面 全身横排  │
│  85mm 浅景深，自然皮肤质感    │  自然站姿，全身入镜含脚部与地面   │
├────────────────────────────┼────────────────────────────────┤
│                            │  右下                           │
│  （主视图可向下延伸占满左列） │  表情板：五格面部半身像横排       │
│                            │  平静·微笑·害羞(或愤怒)·难过·惊讶 │
└────────────────────────────────────────────────────────────┘
```

- **左侧 主视图**：头肩/胸像特写，85mm 镜头、浅景深；呈现五官细节、发型正面全貌、
  标志性配饰与妆面。这是换脸与面部一致性工具的首选源图。
- **右上 三视图**：同一位角色的正面、侧面、背面全身照横排；自然站姿、双臂自然下垂、
  **全身入镜（明确露出脚部、鞋子和地面，不得在踝部裁切）**；同一套服装、同一打光。
- **右下 表情板**：五格面部/半身像横排——平静、微笑、害羞、难过、惊讶（表演向角色可换
  「愤怒」替「害羞」，在 `taste_option` 里声明）；五格同一构图、同一打光、同一发型配饰。

## 2. 一致性硬约束（逐字进提示词）

- 每一格都是**同一张脸**；脸和身材比例完全一致；所有分格角色形象一致。
- 所有分格**打光一致**：柔和影棚光、浅灰色无缝影棚背景、细净分割线。
- 发型、发色、标志性配饰（如发饰、耳坠、项链）在**所有分格中保持一致**。
- 身材比例按项目设定写死（如身高、头身比、体型关键词），三视图中不可漂移。
- 质量词组：`8K 超精细，照片级写实，真人，实拍摄影，单反摄影，商业影棚拍摄，
  清晰对焦，高分辨率，自然比例，正确人体结构`。
- 排除项：不同格身份不一致、打光不一致、多余人物、裁切脚部、背景杂物、3D 感（按项目风格）。

## 3. 提示词骨架（中文出图模型用；英文模型逐段对照翻译）

```text
[质量/媒介] 专业模特参考板，影棚模特卡排版，横向构图，浅灰色无缝影棚背景，细净分割线，
8K超精细，照片级写实，真人实拍，柔和影棚光，所有分格打光一致。

[左侧主视图] {角色名}的特写肖像，{五官锚点：脸型/眉眼/鼻/唇/肤色/妆面}，{发型锚点+发饰}，
{标志性配饰}，85mm镜头，浅景深。

[右上三视图] 同一位角色的三张全身照片横排——正面、侧面、背面，自然站姿，全身入镜含脚部与地面，
脸和身材比例完全一致，同一套服装和打光，从所有角度均可清晰看到{发型锚点}和{配饰}。

[右下表情板] 同一位角色的五张面部表情半身像——平静、微笑、害羞、难过、惊讶——同一打光，
同一构图，身份一致，{发型锚点}和{配饰}在所有表情中保持一致。

[服装] {当前 Look 的服装锚点，来自视觉设定.md 的连续性锁}。
[身材] {项目设定：身高/头身比/体型关键词}。

清晰对焦，高分辨率，单反摄影，商业影棚拍摄。
```

## 4. 与项目文件的对接

- 板中所有 `{锚点}` 必须取自 `视觉设定.md` 对应人物条目的**识别锚点 / 连续性锁 / 画面代称**，
  不得臆造；`图片提示词.md` 中该板条目的 `REF-` 槽位用途写 `角色参考板`。
- 表情板五格对应 `taste_option` 的表情范围声明；换表情集合需回 `assets` 更新人物条目。
- 三视图是分镜「视觉依据」引用多角度时的首选依据源；主视图是面部特写镜头的首选依据源。
- 每格内容与 [通用配方](common-recipe.md) 的写作顺序一致：用途+身份锚点 → Look → 构图/视图/
  表情 → 材质光线 → 背景 → 保持与排除。

## 5. 从风格包原型到完整参考板提示词

人物原型库：[character-archetype-gallery.md](character-archetype-gallery.md)——按风格包给出年代标志性形象
（如 cn-90s 杀马特系、港剧军装警察、清宫格格、台式校园女生），每个原型附"参考板直填段"。

**填充公式**：

```
参考板提示词 = 板式行（影棚模特卡/横向构图/浅灰无缝背景/细净分割线/8K超精细/照片级写实/
              真人实拍/柔和影棚光/所有分格打光一致）
            + 左侧段（面部锚点 + 发型 + 妆容 + 配饰，取人物条目识别锚点）
            + 右上段（正/侧/背三视图全身横排，服装发型取原型直填段）
            + 右下段（五格表情板，身份一致性元素复述）
            + 服装段（原型直填段，过穿越校验）
            + 身段段（身形与比例，按人物条目）
            + 收尾行（每一格都是同一张脸/角色形象一致/清晰对焦/自然比例/正确人体结构）
```

**工作示例**（tw-youth × 校园女生，脸为虚构锚点）：

> 专业模特参考板，影棚模特卡排版，横向构图，浅灰色无缝影棚背景，细净分割线，8K超精细，
> 照片级写实，真人，实拍摄影，柔和影棚光，所有分格打光一致。
>
> 左侧：温柔年轻女性的特写美妆肖像，自然皮肤质感，精致五官，杏眼圆润，饱满卧蚕，
> 纤长睫毛，小巧鼻头，淡粉嘴唇，清透校园淡妆。黑色长直发配齐刘海，右侧浅蓝蝴蝶结发饰，
> 单边小巧耳钉。85mm镜头，浅景深。
>
> 右上：三张全身照片横排——同一位女性的正面、侧面、背面，自然站姿，全身入镜，
> 脸和身材比例完全一致，同一套服装和打光，从所有角度均可清晰看到长直发和蝴蝶结发饰。
>
> 右下：表情设定，同一位女性的五张面部表情半身像——平静、微笑、害羞、难过、惊讶——
> 同一打光，同一构图，身份一致，蝴蝶结发饰和耳钉在所有表情中保持一致。
>
> 服装：白色衬衫校服、格纹百褶裙、白色布鞋、双肩书包。
>
> 身材：青春少女自然比例，身形挺拔，体态匀称。
>
> 安静温柔的校园女生，照片级写实，真人，实拍摄影，自然比例，正确人体结构，
> 每一格都是同一张脸，所有分格中角色形象一致，清晰对焦，高分辨率，单反摄影，商业影棚拍摄。

**对接规则**：
0. 选原型按五维标签过滤（年龄/职业阶层/性格/正反派阵营/性别），正反派用 §0.5 变体规则调五处，年龄变体用 §0.8 族谱；
1. 面部锚点永远来自人物条目（原型不管"这张脸"）；发型/妆容可由原型补足年代感
2. 服装段逐字取原型"参考板直填段"，再按人物条目调整（同一包内不同阶层换原型条目）
3. 完整提示词定稿前过两道校验：style-packs.md 造型指引禁用元素 + 人物条目连续性锁
