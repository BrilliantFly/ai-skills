# 平台审核规避词表（Seedance / 即梦类）

> 视频与关键帧提示词送平台生成时可能被内容审核拒掉。本词表给两类工具：
> **安全改写**（把高风险表述换成可见描写）和**拒审后排查**（二分定位敏感词）。
> 原则：描述**镜头里看得见的东西**，不描述剧情定性词——这本来也是好提示词的写法。

## 高风险类别 → 安全改写

| 类别 | 高风险写法 | 安全改写（可见描写） |
|------|-----------|-------------------|
| 打斗暴力 | 杀死、砍杀、血溅、爆头、虐打 | 招式动作写实描述：挥刀劈下、格挡后退、踉跄扶墙；伤口写"衣袖破损"不写血 |
| 血腥 | 鲜血、尸体、断肢 | 深红色液体留在画面外；倒地不动、镜头切反应 |
| 武器管制 | 枪械具体型号、制式武器 | 长刀、短刃、棍棒等冷兵器直接写形制；现代枪械写"黑色金属器械"并降低出现频次 |
| 人物身份 | 真实演员名、领导人、宗教人物 | 一律本项目角色锚点描述（脸走角色参考板，本来也是硬规则） |
| 未成年人风险 | 儿童单独 + 危险场景 | 儿童镜保证有成年人在画内或改为远景剪影；不写"独自夜出"类表述 |
| 穿着暴露 | 敏感身体部位直白描写 | 服装形制与材质描写（露肩剪裁、开衩长裙），镜头写构图不写身体部位特写 |
| 品牌/Logo | 真实品牌名、包装文字 | "无标识的白色瓶子""纯色易拉罐"；文字类内容一律避免可读文字 |
| 违禁品 | 毒品、赌博用具直白描写 | 烟盒、纸牌等模糊化处理或道具化（道具板里提前定义） |
| 地标/国界 | 可识别真实地标、地图 | 类型化场景母题（风格包已保证），架空城市名 |

## 通用红线

1. **长提示词惩罚**：单条提示词超过约 300 字，平台指令跟随明显变差——优先精简，不是堆词
2. **不写剧情定性**：`复仇`、`背叛`、`阴谋` 这类词模型画不出来还可能触发审核——只写可见动作与表情
3. **画外处理**：必须保留的暴力/敏感剧情事实，写在分镜/剧本的**文档层**（给人看），不进提示词（给模型看）

## 拒审后排查流程

1. **二分定位**：把提示词砍半重试，锁定敏感段落；通常是一两个词
2. **同义替换**：用上表改写；仍拒则把该内容改为**画外/留白**（镜头切反应、声音暗示）
3. **降频重试**：同一画面反复拒审时，拆掉修饰从句只留主体动作，先过审再逐层加回
4. **记录**：确认的改写对回写进《视觉设定.md》连续性锁或道具板，避免下次再撞

## 与既有规则的关系

- 本词表只约束**送平台生成**的文本；《剧本.md》《分镜.md》文档层不受限
- 关键帧正文与视频提示词的既有格式（REF 槽位、方言语法）不变，词表只在选词层生效
