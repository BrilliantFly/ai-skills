# 集间延长衔接语法（Seedance 类平台）

> 目标平台支持**视频参考**时（如 Seedance 2.0 的 `@视频X`），同一连续动作跨集时可用
> "延长"语法衔接，比首尾帧拼贴更顺。本手册是 [Seedance 方言](seedance-2.0.md) 之外的
> 补充选项，方言主规则不变。

## 两种衔接方式怎么选

| 方式 | 适用 | 机制 |
|------|------|------|
| **冻结关键帧衔接**（默认） | 每集独立成片、动作可断开 | 下一集首镜冻结关键帧 = 上一集收尾画面，走既有 REF `用途：起始帧` 路径 |
| **延长衔接** | 同一连续动作被集长切断（长打斗、长追逐、一镜到底段落） | 上一集成片作为视频参考上传，提示词首行写延长指令 |

判断标准：观众**能不能察觉集与集的接缝**。能切断 → 默认方式；切不断 → 延长衔接。

## 延长衔接写法（Seedance 2.0 格式）

```
图片1: C01（角色参考）
图片2: S03（场景参考）
视频1: 上一集成片（动作连续性参考）

将@视频1延长15s，[延续的动作描述]，[本集新增的可见变化]
0-3s画面：…
3-6s画面：…
…
【声音】…
【参考】@图片1 身份，@图片2 地理，@视频1 动作连续
```

## 规则

1. **上传物**：`视频1` 用上一集**成片**（不是草稿、不是单镜导出）；文件由创作者从平台历史或本地成片提供
2. **用途声明**：`@视频1` 只声明 `动作连续`——取动作与运镜惯性，**不取人物脸**（脸仍由角色参考板图片控制，防止视频参考把脸拉漂）
3. **首行指令**：`将@视频1延长15s` 必须是提示词第一行；本集时长照常受目标模型原生时长约束
4. **节拍表照写**：延长段落同样按 `$short-drama-storyboard` 的「长镜节拍」（`long-shot-beats.md`）出时间轴分段（方言支持时逐拍转写）
5. **链条记录**：《分镜.md》本集首镜的「输入参考图」写 `PLAN-EP<上一集>-LAST（…）《上一集成片》（用途：动作连续；…）`，声明这是生成时创作者手动挂载的视频参考
6. **审核风险**：延长段落整段过审后才算就绪；被拒时按 [平台审核规避词表](platform-safety-lexicon.md) 排查，或退回冻结关键帧衔接

## 与方言的关系

- 仅 Seedance 2.0 / 2.5 方言下提供；MiniMax H3、Wan 等方言不支持视频参考时，一律默认冻结关键帧衔接
- 本手册不改变方言主文档的槽位上限、时长约束与格式校验，只新增"视频1"这一种合法参考类型
