# 镜间交接帧（handoff）

> 解决的不是"这一镜好不好看"，而是"两镜接起来像不像同一场戏"。
> 判据只有一句：**后一镜的起始帧，是不是前一镜真实结束的那一帧。**

## 为什么必须写

分镜文本写对、视频模型也画得对，成片仍会"场景乱跳、打斗不连贯"，因为下游把每一镜当成
**独立的一次生成**：读一张首帧、按提示词自由发挥五到九秒。中间没有任何东西把上一镜的
人物站位、光位、地面湿干、兵器角度带过来。

实测（EP001 第一章 8 镜，逐镜独立生成后拼接）：

- 8 张起始帧色温 R−B 从 +10.1 摆到 −19.1，亮度 37.8→60.9；
- 镜间像素差 MAE 26–65，亮度跳变最大 −44、色温跳变 +31；
- 观众看到的是"换了一场戏"，不是"接了一个镜头"。

所以交接帧不是美术锦上添花，它是**唯一能让两镜在物理上接住的东西**。

## 什么时候必须写

满足任意一条即必须写 `用途：结束帧` 槽位，并让下一镜复用同一张图作 `用途：起始帧`：

1. 同一空间内的**连续动作**被拆成两镜以上（对打、追逐、拆招、多人围攻、连续位移）。
2. 相邻两镜在同一 `EP001-SCxxx` 内，且前一镜的「终点」不是静止收势（人物还在动、兵器还在走）。
3. 前一镜的终点状态会**约束**下一镜起点（谁握着什么、刀在哪、血在哪、竹断在哪）。
4. 下游模型是"每镜独立生成"的（MiniMax H3 的 `r2v`/`i2v`/`fl2v` 都属于此类）。

以下情况允许不写：真正的硬切换场（跨场景、跨时间）、蒙太奇并列镜、
前一镜以静止收势结束且下一镜是新的信息单元。

## 怎么写

### 1. 分镜表里成对出现

前一镜：

```
- **输入参考图**：REF-SHOT-008-START（顺序：1）· 剧集/EP001/制作成果/images/SHOT-008·断流.png《断流起始帧》（用途：起始帧；控制：…；不得控制：…）；
REF-SHOT-008-END（顺序：2）· 剧集/EP001/制作成果/images/SHOT-008·断流_END.png《断流结束帧》（用途：结束帧；控制：本镜终点姿态与刀剑接触点；不得控制：下一镜的运镜与景别）
```

后一镜：

```
- **输入参考图**：REF-SHOT-009-START（顺序：1）· 剧集/EP001/制作成果/images/SHOT-008·断流_END.png《断流结束帧》（用途：起始帧；控制：入场姿态、光位、地面状态；不得控制：本镜终点状态、镜头运动）
```

注意三件事：

- **同一个文件名**出现在前一镜的 `结束帧` 和后一镜的 `起始帧`，不是"描述相近"而是同一张图。
- 槽位 ID 可以不同（`REF-SHOT-008-END` / `REF-SHOT-009-START`），但路径必须逐字相同。
- 后一镜的「起点」文字必须与前一镜的「终点」文字对得上；只改图不改字，提示词会把模型拉回别处。

### 2. 图的来源：抽帧优先，重绘次之

按可靠性从高到低：

1. **从前一镜已生成视频的末帧抽帧**（`ffmpeg -sseof -0.1`）。这样图与视频严格一致，是最好的。
2. 若前一镜尚未生成，用**同一张场景板 + 同一句光位 + 同一 seed** 出前一镜的结束帧，
   再把它直接当后一镜的起始帧。
3. 最差：两镜各出一张"描述相近"的图。这等于没做交接，只是把误差写得更清楚。

### 3. 光影与空间一起锁

交接帧只管画面，不管提示词。要额外做两件事，否则图接上了、文字还在把模型往别处拽：

- 相邻镜的冻结关键帧正文**共用同一句光与色温**（逐字相同，不改写）。
- 相邻镜的提示词不重复写"黄昏/暮色"这类会漂移的词，改写成具体光位：
  「光从西侧竹隙斜下，暗部保留细节，地面亮暗成段」。

### 4. 与"每镜一条音轨"的冲突

`minimax-h3` 一镜只解一条音轨，交接帧不改变这条限制：上一镜的台词仍在上一镜里说完，
下一镜要么无台词、要么换人说话。**不要为了接画面把台词跨镜拆开**。

## 执行端怎么用

- 首尾帧模式（`fl2v`）：`结束帧` 直接进尾帧槽位，首帧槽位由上一镜尾部接管，链路最稳。
- 参考主体模式（`r2v`）：把 `起始帧` 作为唯一一张图送入，其余身份板/场景板按需减到最低；
  图越多，模型越是"平均"，交接帧的作用被稀释。
- 无论哪种模式，**都要让整条时间轴在同一次运行里生成**。把镜头一镜一镜单独提交，
  段间引导（`continuityEnabled` + `continuityOverlapFrames`）会因为找不到上一段而整体失效，
  交接帧写了也白写。

## 反例（写了但没用）

- 前一镜写"长剑脱手飞向竹坡"，后一镜起始帧仍是"两人对峙"——图没接住动作。
- 前一镜末帧是人物特写，后一镜起始帧却是大全景——景别跳变被当成"切换"，观众读到的是跳场。
- 两镜都挂"场景板"但没有共用结束帧——场景板只保证"是同一种景"，不保证"是同一个地方"。
- 逐镜单独提交再拼接——这是最常见的一种：交接帧齐备，段间引导关闭，接缝依旧是硬切。
