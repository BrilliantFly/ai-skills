# 转场手艺（跨场衔接与时间省略）

> 管**集内跨场**的衔接设计：上一场怎么收、下一场怎么接、中间的时间怎么省。
> 集间衔接另有机制（冻结关键帧投影 / Seedance 延长语法），本手册不重复。
> 一句既有原则是地基：**终点应能成为下一镜可信起点**——本手册把这句展开成可执行写法。

## 转场契约（写在《分镜.md》两边）

跨场时，上一场末镜与下一场首镜互为契约，各加一行：

- **上一场末镜「转场交出」**：终点画面里埋下的接续物——动作惯性（正在关门的门缝）、
  声音预入（下一场的火车汽笛提前 1 秒进入）、视线方向（人物看向画外）
- **下一场首镜「转场接住」**：起点如何承接——匹配的动作相位、同方向的声音延续、
  接住视线的画外对象

两边字段必须对得上：交出"关门动作惯性"，接住就必须是"门已关上/正合拢"，
不能接住一个无关的静态画面。**契约只写可见/可听的实体，不写剧情定性词。**

## 转场手法库（按信息收益选，不按花样选）

| 手法 | 写法 | 什么时候用 |
|------|------|-----------|
| 硬切 | 末镜终点 = 首镜起点，无附加 | 默认；时间紧、节奏快 |
| **动作接动作** | 末镜终点是动作 A 的半程（抬手），首镜起点是同一动作的下半程（放下/落点） | 同人跨场连续动作；最顺滑 |
| **匹配剪辑** | 末镜与首镜构图/形状呼应（圆月→圆井口） | 时空跳跃但有视觉母题 |
| J-cut | 下一场声音先入（末镜后半段听到下一场对白/音效） | 对白场换场；提前给观众"要去哪" |
| L-cut | 本场画面切走、声音拖进下一场开头（上一场的回声/旁白） | 收尾情绪需要延续 |
| 声音桥 | 双向：末镜尾 J-cut + 首镜头 L-cut 组合 | 大跨度转场（跨城/跨天） |
| 空镜过渡 | 插 1 个无人物镜头（环境/物件/天气）承转 | 时间省略、情绪喘息；空镜也须有视觉依据条目 |
| 光线预入 | 首镜起点光线变化暗示时间（日落色→夜） | 同场跳时 |

选择规则：每场转换先答"观众需要什么信息来重建时空"——**答案决定手法**；
连续硬切超过 3 场时审视是否全部真的可以硬切。

## 时间省略（剧本写"三天后/当晚/翌日"时）

| 省略幅度 | 默认表达 | 禁忌 |
|---------|---------|------|
| 同场数分钟 | 光线微变 + 状态差（烟灰缸多了） | 不用字幕卡 |
| 同日跨时段 | 光线预入（色温/角度写进首镜起点） | 不靠服装突变暗示 |
| 跨日/跨城 | 空镜或 J-cut 声音桥 + 首镜起点写日期性可见物（日历/车票/新伤） | 字幕卡由剪辑单决定，分镜只留接缝 |
| 大跨度（数月/数年） | 造型状态变体（见图片提示词端 look-and-state-variant）+ 匹配剪辑 | 关键帧不写"已经过去三年"这类叙述 |

**状态差必须可冻结**：省略后的变化（新伤、搬家、换装）要在首镜冻结关键帧里可见，
并登记进《视觉设定.md》对应条目的状态栏（有状态变体条目时引用它）。

## 检查清单（跨场时逐条过）

1. 末镜「转场交出」与首镜「转场接住」字段对得上
2. 手法有信息收益（不是为花而花）
3. 时间省略的可见证据进了首镜关键帧与视觉依据
4. 声音桥的预入/拖尾写进两镜的「声音」字段，时长各 ≤2s
5. 拆镜后跨场契约不失效（修订时同步刷新两边字段）
