# 武打身体依据（兵器、拳掌与腾跃的可拍签名）

> `craft_default`。本文件只管一件事：**这一招的身体与兵器到底怎么动**——主战距离、发力链、
> 接触点的强弱区、兵器用完之后的回收负担。
>
> 它**不覆盖**也不重述 [肢体互动手艺](physical-interaction-craft.md)：攻防相位三选一、受击反应
> 三选一、连招按镜像容量、终点停在未落定、器械接触点写在本体上、本体余态三选一——那些规则的
> 唯一权威仍是那份文件的 §四与 §五。两处说法不一致时**以那份文件为准**，本文件的取值表作废。
> 一对多与混战的轮次编排见 [调度手册](blocking-playbooks.md#5b-围攻与轮次一对多混战)，本文件不重复。

招式名不能代替身体路径，这条既有规则已经写明。本文件提供的是**取词方向**：当模型或负责人
只会写"他一剑劈出"时，下面各行给得出可以拍的具体差异。全部条目按身体力学与兵器形制重写，
不含任何具体作品、人物、门派或演员的专名；引用外部资料时同理。

## 一、兵器与拳掌的身法签名

每一类只回答四个问题：多近才打得到、力从哪条链出来、哪一段兵器是强区哪一段是弱区、
一招用完之后身体欠下什么。写完招式把四项对一遍，缺一项就说明这一招还没被想清楚。

| 类别 | 主战距离 | 发力链 | 接触点强弱区 | 回收负担 |
|------|---------|--------|-------------|---------|
| 单手长剑 | 一臂加半剑身；贴身即失效 | 后脚蹬地→转腰→肩→腕，剑走弧线或直线由相位决定 | 前 1/3 段切、中 1/3 段压、护手附近弱，格挡优先用中前段 | 刺出后剑身空、腕被拿；劈砍后需顺弧线回撩才换方向 |
| 单刀 / 横刀 | 比剑更近，刀背可靠前臂 | 腰胯带刀，横斩与斜劈多，少直刺 | 刀刃中段最实，刀尖轻、近柄处只宜架 | 刀形带弯，收刀时刀尖先过身体，占位比剑大 |
| 重刃长柄刀 | 一身高，横扫半径最大 | 双手分握、肩髋同转，靠自重与下落加力 | 前段劈砸强、柄部只可架与撞 | 力劈落空后**整条线短暂失守**，重力抬不回来，是对手贴身的窗口 |
| 长枪 / 矛 | 最长，地面角度决定可用长度 | 后手顶腰、前手导尖，拦拿扎三动作是同一发力链的不同出口 | 枪尖与枪头下三寸强，枪身中段弱、可被压弯 | 扎老（刺出过深）需整条收回；被贴住就要用杆尾与摔 |
| 长棍 | 双手之间与两端各一段 | 转腰送棍，横扫与劈砸靠棍头重量 | 棍头强、握把处无攻击性 | 舞花要接住下一击方向，扫空后棍身回绕需半拍 |
| 双短兵（双刀/匕首/爪刺） | 必须进入臂圈内 | 双链同时但不双主：一手主攻一手只开路或封 | 内圈短促，无远端 | 一手出招即空一侧；两手交叉会互相挡视线与路径 |
| 软兵与带绳法器（鞭/链/伞） | 半径可变，落点不固定 | 起势必须先给方向再放，靠离心而不是臂力 | 末端速度最高但**不可中途改线** | 收势需反向抖回，否则自身被拖；被近身即废 |
| 拳掌（短桥） | 一步之内 | 后脚—胯—肩—肘—手，掌根或拳面收力 | 中距掌根强、贴肘只剩肩撞 | 每次出手都带半身向前，落空即重心送出 |
| 腿法 | 比拳长半臂，单腿支撑期是破口 | 支撑腿蹬、跨送、小腿甩出 | 胫骨与脚背强，膝窝弱 | 收腿需半拍落地，连两次踢击必掉重心 |
| 投掷与暗器 | 取决于器物重量，不追"百发百中" | 转体送肩，出手角决定抛物线 | 飞行期投掷者无主要武器 | 需要回收动作或余量登记，否则下一镜凭空多出一把 |

## 二、可拍招式动词（写身体，不写名目）

只作取词参考，用之前必须落到部位、方向与后果上，仍按 §四「打击点与受力方向」的要求写全。

- 长剑：反手撩腕、压刃抢中线、拖剑引步、贴腕滑削、跨步截刺、回身带剑格、剑背拍持械手
- 单刀：降髋外侧切步、低位回旋斩接横架、借第一次接触的反扫、错步绕向对方柄侧、反撩逼跳后力劈封落点
- 重刃：拖刀走弧线起手、举过头顶借下落力劈、以柄端上挑、砸地反弹改线（要求写明地面反应）
- 长枪：拦开刃口、拿住杆身下压、扎喉改扎腕、回抽带枪扫腿、杆尾撞肋、贴杆推顶夺线
- 长棍：横扫膝线、劈头接绞棍、戳棍点肩、扫地棍断支撑腿、跳跃劈棍（写明起跳支撑与落点）
- 双短兵：一手架开一线、另一手同期短刺；交叉反手割、贴肘内缠、双持改单持夺械
- 软兵：甩出定角、绕颈一周收紧、贴地弹扫、抖回收势（写明收势时谁被拖）
- 拳掌：掌根推下巴改线、短桥压臂开线、肘击抢内圈、抓手反拧夺械、膝撞断支撑
- 腿法：低扫断根、中段蹬膝、上摆逼后仰、后蹬撤步、连续第二腿必写重心掉向

## 三、武侠特有的两类写法边界

**轻功与腾跃**（治"漂浮式轻功"这类失败）：

- 每次离地都要有**可见的支撑与方向**：蹬哪一块地/瓦/墙面、身体朝哪走、空中只能改落点，
  不能改目标——腾空后再换攻击对象是第二个动作，按镜像容量另起一镜
- 落地必须有受荷反馈：膝弯、脚下扬尘或碎瓦、衣摆前冲、重心前送出半步；不写这些会被画成无声飘落地
- 同一场连续腾空镜 ≤2；第三次起跳要么交出攻防（在空中被打），要么改走地面低桩
- 借力点属于道具或地点条目：踩断的竹、塌的屋脊、墙面脚印要在《视觉设定.md》里有承载，
  否则按既有规则不许凭空新增环境物

**气与法术的可见化**（只在项目形态允许超常设定时使用）：

- 灵气、剑光、符火都必须给**一个方向 + 一个数量级**：前推、上冲、下劈、爆散、环绕五选一，
  只写"灵气爆发"会被画成环绕特效乱撒；火花与碎屑各写一个方向，沿用 §五 的"效果层不堆叠"规则
- 超常输出要有前置代价或条件登记（谁给的、什么状态才能给、用完少了什么），写进剧本层，
  不在分镜层首次发明；本项目若已锁定写实武打形态，本节整体不适用
- "以快打慢""气势压人"这类不可拍的定性词继续禁用，与已锁定的武打风格子包不冲突：子包规则见
  `short-drama-develop/references/style-packs.md` 的「武指/打斗风格子包（动作文法层）」（由分镜 SKILL.md
  的按需知识入口加载，本文件不重复它），子包管攻防密度、镜头跟打法与变速点归属，本文件管单镜身体路径

## 四、`- 武打：` 登记行（可选字段）

写了这一行，本镜就进入武打机械核对；**不写就等于旧文档**，一切照旧，不新增任何要求。语法三段，
用 `/` 分隔，顺序固定：

```text
- 武打：兵器·横刀 / 相位=接触瞬间 / 姿态=低桩
```

- `兵器·X`：X 必须与《视觉设定.md》的道具条目同名（徒手就整段不写这项）
- `相位=`：只能是 `起手` / `接触瞬间` / `收势`，与 §四 攻防相位三选一同名同义
- `姿态=`：只能是 `低桩` / `腾空` / `转身` / `特写` / `自由站姿`
- 确要连续同相位（例如三连格挡推进、三连收势后的余震），在这几行末尾追加 `连相`，机械门会放行

字段只登记机械可核对的三项。招式名、受力后果、器械余态继续写在 `- 唯一动作：`、`- 终点：`
和关键帧正文里，本行不承载叙事内容，也不能替代它们。

## 五、写完自检（接在 §五 自检 11–14 之后）

15. 本镜的距离、发力链与接触点强弱区是否落在同一类兵器上，没有出现"剑的贴身用法定位成长柄"这类矛盾

18. 声明了 `- 武打：` 的镜，兵器是否已是《视觉设定.md》道具条目并按需上锁
19. 借用外部招式资料时，是否只取了机制；条目原文、专有名词与不存在的条目都没有写进正文
