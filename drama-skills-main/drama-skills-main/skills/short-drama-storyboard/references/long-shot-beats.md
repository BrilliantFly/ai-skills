# 长镜节拍分段（镜内时间轴）

> 与「起点 → 唯一动作 → 终点」完全兼容：状态链不变，本手册只解决一件事——
> 镜长 ≥ 8 秒时，单一状态链在视频模型里容易被压成一团，需要按时间轴拆成节拍。
> 节拍是**计划工具**，不新增镜头职责、不改变起止边界。

## 什么时候分拍

- 镜长 ≥ 8 秒，且本镜状态链含 2 个以上可辨认的子动作（如"绕到左侧→夺刀→逼退"）
- 目标模型原生时长上限内的大动作镜（MiniMax H3 10-15s、Seedance 15s 档）
- 对白镜按 [对白估时] 已算出发声占镜长 60% 以上时，动作与台词也需分拍对位

镜长 < 8 秒，或状态链只有一个可见动作时，**不分拍**——直接写状态链。

## 分拍规则

1. **节拍数**：3-5 拍；每拍 2-5 秒，短拍不短于 2 秒（再短模型跟不上指令）
2. **边界语义**：每个节拍边界必须是状态链上的**中间状态**，不得引入新动作或新职责——
   节拍只是把"从起点到终点的那条可见状态链"按时间展开
3. **每拍三要素**：时间区间 + 该拍结束时可见的姿态/位置 + 与上一拍的差异点
4. **峰值对位**：剧本标注的相对时间边界（"后半段首次出现"等）必须落在某一拍边界上
5. **声音对位**：有台词时，发声区间写入对应节拍；动作不得与发声不能并行的时段重叠

## 节拍表格式（写在《分镜.md》本镜条目内，「唯一动作」之后）

```text
节拍：0-3s（起手对峙，刀仍在鞘）→ 3-6s（拔刀一闪，对方侧身）
     → 6-10s（贴身缠斗两回合，刀口停在肩前）→ 10-12s（逼退三步，收势）
```

- 时间区间必须与镜长相等且无缝隙、不重叠
- 写完后自检：把节拍连读一遍 = 「唯一动作」原文？连不出来就是节拍私加了动作，改

## 与下游的衔接

- 目标方言支持时间轴格式（如 Seedance 的 `0-3s画面：…` 分段）时，节拍表**逐拍转写**进视频提示词正文
- 方言不支持时间轴时，节拍表仍是动作量预算的依据：每拍被"压掉"即说明镜长不够，回本阶段拆镜
- 多镜容器内的短镜不单独分拍；容器整体可按同样规则出一张容器级节拍表
