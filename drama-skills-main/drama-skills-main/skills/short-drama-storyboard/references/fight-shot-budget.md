# 武打镜的容量与配额（防扎堆、防整招塞一镜）

> `craft_default`，带三条机械门。本文件管**一镜装得下多少、整集武打镜的分布是否读得清**，
> 不管招式本身怎么写（那在 [肢体互动手艺](physical-interaction-craft.md) §四/§五 与
> [武打身体依据](martial-action-library.md)）。
>
> 配额是**下限防呆**，不是创作目标：它只在被点名的武打场生效，事务场、过场、纯情绪场不受约束，
> 也不许为了凑配额新增动作或腾空。凑数造成的等价站桩比扎堆更糟。

## 一、一镜装得下多少

沿用既有判据，不给公式：一镜一个相位、一个可见状态闭合点，连招数量由镜长与状态变化数决定
（§四「连招按镜像容量走，不按招数走」）。

**禁止的换算**：不写"每秒攻击 ≥N 次""每镜 ≥3 招"这类阈值——模型没有速度与动量概念，
这类数字既不执行也不可读，只会把动作写成随机挥动。想要"快"的效果，靠**短促动词与方向**
（见 `$short-drama-video-prompts` 的动作时间与同时性）与更短的镜长，不靠形容词也不靠计数。

反过来，一条时长要用镜内节拍承载：≥8s 的武打镜按 [长镜节拍](long-shot-beats.md) 分 3–5 拍，
每拍边界仍是中间状态，不是新增招式。

## 二、武打镜的姿态与景别配额（登记了 `- 武打：` 才计算）

把本集所有声明了 `- 武打：` 的镜按场聚合，**同一场武打镜 ≥6** 时按下限自查：

| 项 | 下限 | 依据 |
|----|------|------|
| 低桩（半蹲/沉马/跪步/仆步） | ⌈n/5⌉ | 重心降低才可拍"被打断支撑"，也让腾空有对比 |
| 腾空或高位 | ⌈n/8⌉ | 只作高度层，仍受"连续腾空 ≤2 镜"上限约束 |
| 转身或背身 | ⌈n/5⌉ | 朝向单一会让相邻镜看起来只是换姿势 |
| 近景特写（手部/器械局部/眼神） | ⌈n/8⌉ | 近景读面部反应，中远景读姿态与位移（受击反应与景别匹配） |

景别另守一条：**同一场武打镜不得有 ≥80% 落在同一档景别**。全集中景是武打戏最常见的失效——
它既读不清接触点，也读不清受击表情，还让相邻镜看起来互相重复。

n=6 示例：≥2 低桩 / ≥1 腾空高位 / ≥2 转身背身 / ≥1 近景特写，且单一景别不超过 4 镜。

## 三、连续同相位

相邻武打镜要交出攻防：起手→接触→收势是三个不同职责的镜。同场**连续三镜相位相同**是缺陷
（三次起手＝三次预备没人落地；三次接触＝没有后果的对撞；三次收势＝同一结果反复播报）。

有意连续同相位（三连格挡推进、余震连镜）在这几镜的 `- 武打：` 末尾追加 `连相`，门会放行——
这是给创作者的豁免，不是默认出口；用之前先自问这三镜的**可见状态**是否真的不同。

## 四、一打多与轮次

轮次只在文档层用，最终仍要落成镜头序列。判据以 [调度手册 §5b](blocking-playbooks.md#5b-围攻与轮次一对多混战)
为唯一权威（一镜只让一组接触成为注意中心；两组共用同一受力方向可留在全景，方向相反必须拆）。
本文件只补两条武打现场的常见走法：

- **攻防权接力**：谁在此刻有攻击权、下一镜交给谁，写进 `- 唯一动作：` 的状态链；
  其余人保持可见的逼近或封位状态，不许"排队等待"
- **落点继承**：上一镜被打退的人停在哪、兵器在哪、重心朝哪，下一镜起点必须接得住
  （§一 接触点跨镜保持 + `SHT-14` 动态对象落点）

## 五、三条机械门对应什么

`- 武打：` 字段存在时，跨文档检查会额外核对：

1. **相位取值**：`相位=` 缺失或不在三选之内 → 报错（同 §四）
2. **兵器建项**：`兵器·X` 与《视觉设定.md》道具条目不同名或未在本镜视觉依据里点名 → 报错
   （§五「兵器一致性是道具连续性」的机械执行）
3. **分布**：同场连续三镜同相位（无 `连相` 豁免），或武打镜 ≥6 且单一景别占 ≥80% → 报错

填 `无` 或半写（只写兵器不写相位）同样报错——登记一半读起来像已经覆盖，实际把门关掉了。
本集没有武打镜时不写这个字段，本文件整体不参与检查。

## 六、借用资料时的纪律

外部招式资料、历史稿件或检索工具给的条目，只作机制与质量标准来源。零命中必须写
「无命中，将原创」；读不到的条目只能报缺失；不得为使用资料改用户锁定的人物、武器、动作顺序、
胜负或写实程度。这几条与分镜既有的"不新增剧本没有的事实"同向，不是新增要求。

## 七、写完自检

1. 本集武打镜是否都登记了 `- 武打：`（或都明确不需要登记）
2. 每镜是否只有一个相位、命中是否交给反应镜或下一镜
3. 同一场武打镜的姿态与景别分布是否过下限，是否出现整场同一档景别
4. 一打多是否写清攻防权接力与落点继承
5. 是否为了凑配额新增了原剧本没有的动作、腾空或环境物——有就删
