# 电影/剧集视觉风格包库

`film-style-visual-reference.md` 的配套风格库。每个包按**五要素**（色盘/光线/景别构图/质感/场景母题）
写成，可直接锁入生产档案（`pack_id` 即下方各包编号）。合规红线与注册方式见主文档，此处不重复。

使用规则：
- 包是**起点不是终点**——锁定后仍可与创作者逐项微调，调整记录进决策
- `竖屏适配`一行：该风格用到竖屏短剧时的取舍得失（多为构图项），横屏项目忽略
- 载体标注（电影/剧集）指风格的原始来源媒介；跨媒介使用是常态，按适配行取舍

## cn-70s · 改革前夜乡土现实（70-80s，电影）
- **色盘**：土黄 #C8A96E（35%）、军绿 #6B7A52（25%）、藏蓝 #32405C（20%）、粗布灰白 #D9D4C7（15%）、灶火暖橙 #C96F33（5%）
- **光线**：自然光优先，钨丝灯暖黄点源，窗格硬光入室，夜晚油灯/煤油灯小光源
- **景别构图**：中远景叙事为主，土墙/门框框式构图，劳动场面的横向群像
- **质感**：粗颗粒、低锐度、轻微褪色发黄、4:3 时代感
- **场景母题**：土坯院落、生产队场院、供销社、大喇叭、搪瓷缸（类型级）
- **竖屏适配**：框式构图保留，横向群像改纵向前后景层次

## 武指/打斗风格子包（动作文法层）

> 与上面的视觉风格包**正交**：视觉包管"看起来像"，子包管"打起来像"。每个子包给主文档 §3 第七要素
> 「动作文法」的五项取值——攻防密度 / 接触方式 / 镜头跟打法 / 剪辑率与变速点 / 禁用动作习惯。
> 兵器接触与受击余态的具体句式见 `$short-drama-storyboard` 的
> 「肢体互动手艺」（`physical-interaction-craft.md`）第五节。
> 子包名是**类型级标签**，不进提示词词面（合规红线同主文档 §2）；只把五项翻译成可见写法。

### action-holdpose · 定格亮相·快切串势（60-70s 棚景武侠）
- **攻防密度**：一镜一势——起手、亮相连做，一势之内不连招；招与招之间靠切，不靠走
- **接触方式**：实交少而准，多数交锋由站位、身段与亮相完成；对掌用隔空定格，掌心不真碰
- **镜头跟打法**：固定机位为主，人物在画框内走位完成调度；亮相瞬间身体定、衣发未定
- **剪辑率与变速点**：短镜高切率（1-2 秒/镜），静在亮相、不在挥击；升格留给亮相帧
- **禁用习惯**：高速环绕跟拍、长镜头连续过招、手持晃动、地面缠斗
- **推荐配对**：视觉包 `wuxia-tvb` / `cn-guzhuang`；**竖屏适配**：亮相改纵向构图、人物顶天立地

### action-sangfu · 阳刚实打·一击一代价（70s 硬派）
- **攻防密度**：连续近身拳脚，两三接触成一镜，每次接触都留可见代价
- **接触方式**：拳脚兵刃入画即中，接触瞬间不闪避、不隔空；受力方向即出画方向
- **镜头跟打法**：中近景正面直拍，轻微手持随动；被击者退、施击者不进画框中心
- **剪辑率与变速点**：中高切率，命中前后各留两三帧缓冲；升格只给倒地与回旋
- **禁用习惯**：飘逸腾跃、空中滞留、无接触的舞剑、把血当装饰
- **推荐配对**：视觉包 `hk-80s-kungfu`；**竖屏适配**：正面直拍天然适配，横移改纵深推拉

### action-flywire · 威亚飘逸·大俯仰（90s 新武侠）
- **攻防密度**：一回合分起—空—落三段，空中换位才是主战场，地面只是起点与终点
- **接触方式**：兵刃轻触即分，接触短而密；长发、袖摆、丝线、飘带是**次级武器**，要写它缠住什么、被什么割断
- **镜头跟打法**：大仰角/大俯角、纵向掠镜（人物从镜头前飞过）、环拍随飞行轨迹；地面镜头只做起飞与落地
- **剪辑率与变速点**：低切率长镜，掠镜瞬间升格、落定瞬间回正常速；变速点必须落在镜内
- **禁用习惯**：贴地写实步法、长时间地面缠斗、把人物固定在画面中央对拍
- **推荐配对**：视觉包 `wuxia-film` / `cn-xianxia`；**竖屏适配**：横向环拍改上下穿行、飞行改纵轴

### action-weapontalk · 见招拆招·器械对话（80s 至今）
- **攻防密度**：一镜 2-3 个可数回合，每招有来处与归处；回合之间有明确的换位或抢位
- **接触方式**：兵刃摩擦、绞压、滑开**写在器械本体**上（接触点位置、角度、往哪边滑、剑身震颤与持械手的跟随）
- **镜头跟打法**：中景与全景保住双手与器械轨迹，随器械小幅跟移；切点落在接触相位，不落在表情
- **剪辑率与变速点**：中切率，**不用慢镜**；重击靠声音、身体位移与器械余态表达
- **禁用习惯**：空中滞留、无接触的比划、把兵器当背景道具、跨镜换兵器形制
- **推荐配对**：视觉包 `hk-80s-kungfu` / `wuxia-film`；**竖屏适配**：器械轨迹优先走画面纵轴

**使用规则**
1. 一个项目锁一个主打斗子包；混用（如空中段用飘逸、兵刃接触段用器械对话）时逐项声明谁负责接触、谁负责镜头
2. 五项取值逐字进下游：攻防密度/接触方式 → 分镜「唯一动作」与「视觉依据」，镜头跟打法 → 「运镜」，
   剪辑率与变速点 → 剪辑单 `- 后期：` 行，禁用习惯 → 交 `$short-drama-review` 作核对项
3. 长短兵器不对等是本层的公共事实：一长一短对打时，短兵方的收益必须写在**抢进入长兵内圈**上，
   长兵方的收益写在**拉开距离与以杆/脊引带**上——不写"以快打慢""以巧破力"这类不可拍的定性词
4. 复刻既有影片的打斗时，先在文本层（小说）落成原创因果链，再进视觉链；进入视觉设定时角色名、
   演员相貌、服化道标志一律按主文档 §2 换为原创可见要素，只有动作文法与风格要素可以带走
