# 电影/导演视觉风格参考包

把"参考某部电影、某地区电影风格或某位导演"翻译成**可执行的可见风格要素包**，
在 develop 阶段定版，向出图、出视频、剪辑三端辐射。

> 本文档与 [creative-reference-intake.md](creative-reference-intake.md) 互补：那边管**故事机制**
> 的参考摄取（明令不抄表达），这边管**画面风格**的参考落地（学可见要素，不搬可识别内容）。

## 1. 注册方式（创作者权威决策）

视觉风格参考属于制作形态级决策，与目标视频模型同级。创作者确认后写入生产档案：

```jsonl
{"decision_id":"CD-STYLE","status":"accepted","target_locators":[{"src":"short-drama","field":"/creator_authority/production_profile/choices"}],"accepted_value":{"style_reference":{"type":"film|region|director","name":"台湾青春片","pack_id":"tw-youth","scope":"全剧","lock_level":"色盘+光线+质感"}}}
```

- `scope`：全剧 / 某线（如回忆线用另一种风格包，双包并存时声明各自适用范围）
- `lock_level`：锁哪几层（至少锁色盘；光线/构图/质感可选）
- 未确认前不向下游传播风格行；已接受后，修改需新的决策记录

## 2. 合规红线（逐条硬约束）

1. **不出现**原片演员肖像、角色名、片名、标志性台词、可识别地标或海报道具
2. **只提取可见的、非独创性的**风格要素：色盘、光线方向与软硬、景别习惯、颗粒质感、氛围母题
3. 人物脸部一律使用本项目角色参考板锚点，**不得描述成"像某某演员"**
4. 风格包只提供"翻译后的要素"，每条仍须过 [creative-reference-intake](creative-reference-intake.md)
   的机制提炼：能离开原片名独立成立的才可用

## 3. 翻译六要素（风格包的固定结构）

| 要素 | 内容 | 下游落点 |
|------|------|---------|
| 色盘 | 4-6 个主色（给中文名+hex），注明各色占比 | 出图风格行、剪辑调色 |
| 光线 | 主光方向、软硬、时段、标志性光效 | 出图、视频风格行 |
| 景别构图 | 常用景别、机位高度、构图习惯 | 分镜机位、lookdev 代表帧 |
| 质感 | 颗粒/柔焦/褪色/帧率感 | 出图、视频风格行 |
| 场景母题 | 该风格惯用的空间与意象（只取类型，不取具体地标） | 02场景设定→地点板 |
| 造型指引 | 该风格下人物的年代/阶层/服装材质/发型配饰习惯，以及**禁用元素**（如 cn-70s 禁现代卫衣） | 视觉设定人物条目、角色参考板服装锚点 |
| 动作文法 | 打斗/追逐类项目必填：攻防密度、接触方式、镜头跟打法、剪辑率与变速点、禁用动作习惯 | 分镜「运镜」「唯一动作」+ 视频提示词运动段 + 剪辑单 `- 后期：` 行 |

## 3.5 人物与场景如何体现风格包（两条通路）

**场景——强绑定**：
- 包的「场景母题」直接作为 02场景设定/视觉设定 地点条目的选址依据（锁 `tw-youth` 则主要场景应落在教室/操场/海边公路一类母题内）
- 每个地点板的提示词 = 母题选址 + 色盘占比 + 光线 + 质感，逐字引用

**人物——双层分工**：
- **内容层（锚点管）**：五官、发型剪裁、服装款式等"是什么"来自 `视觉设定.md` 人物条目的识别锚点；但锚点**必须在风格包的「造型指引」约束内编写**（年代、材质、阶层不得越界）
- **呈现层（风格管）**：打光、上色、颗粒等"怎么拍"由色盘/光线/质感逐字进角色参考板与所有人物镜头提示词
- **一致性校验**：人物条目定稿时逐项对照「造型指引」的禁用元素清单，出现穿越元素（年代包里出现不属于该年代的服装/物件）判 FAIL，改锚点而不是改包

## 4. 预置风格包

完整风格库见 [style-packs.md](style-packs.md)：覆盖大陆 70 年代至今（乡土现实/90年代变革/
千禧都市剧/新现实主义/史诗大片/古装正剧/仙侠古偶）、香港（功夫黄金年代/市井霓虹/冷峻警匪）、
台湾（青春片/静观文艺片）、韩国（犯罪惊悚/爱情剧集/古装史剧）、美国（复古冒险/超英/IMAX 冷峻/
A24 作者/现代西部），共 28 包，均标注原始载体（电影/剧集）与竖屏适配提示。
其中武侠类视觉包 4 个（hk-80s-kungfu / wuxia-tvb / wuxia-film / cn-xianxia）；**打斗怎么打**另立一层
子包，见 [style-packs.md](style-packs.md) 的「武指/打斗风格子包（动作文法层）」，与视觉包独立锁、可混搭。

**导演风格包（填空式模板）**——参考具体导演时按五要素逐项填写，只取可见要素：
- 是枝裕和式：自然光家居、固定机位、餐桌母题、低机位平视、克制表演幅度
- 韦斯·安德森式：居中对称、糖果色平面正拍、横移跟拍、字幕卡分章
- 张艺谋式：单一大块主导色统治全画面、色彩即情绪、仪式感群像构图
- 其他导演：先按五要素列候选，创作者逐项确认后才锁

**武指/打斗风格子包**——只锁"打起来像什么"，与上面的视觉五要素正交：
- 定格亮相派：一镜一势、亮相即静、快切串势；禁长镜连招与环绕跟飞
- 阳刚实打派：拳脚入画、一击一代价、命中前后各留两三帧；禁无接触舞剑
- 威亚飘逸派：空中换位为主战场、大仰角俯角、掠镜升格；禁贴地写实步法
- 器械对话派：兵刃接触写在器械本体、一镜 2-3 个可数回合、不用慢镜；禁空中滞留
五项动作文法（攻防密度/接触方式/镜头跟打法/剪辑率与变速点/禁用习惯）的完整取值见
[style-packs.md](style-packs.md)；同一片场可混用两个子包，但必须逐项声明谁负责接触、谁负责镜头。

## 5. 下游落点（三端辐射）

1. **视觉设定.md**：风格包摘要写进项目级风格声明；人物条目按「造型指引」编写并过禁用元素校验，地点条目按「场景母题」选址；与锚点冲突时以锚点为准（风格管"怎么打光上色"，锚点管"是什么"）
2. **图片提示词.md**：每条提示词风格行按色盘+光线+质感逐字引用；lookdev 代表帧用风格包做A/B比较基准
3. **视频提示词.md**：REF 槽位 `用途：风格` 绑定风格包产出的定调图；正文风格行与图一致
4. **剪辑单.md**：调色提示按色盘写（如"整体暖褪色 +5，高光柔化"）；集间调色参数复用，防跨集跑色
5. **背景音乐**：配乐风格包见 [music-style-packs.md](music-style-packs.md)（音频五要素：编制/节奏速度/情绪曲线/标志性处理/用途映射，14 包），与视觉包独立混搭（配对矩阵见该文档）；时间线音乐提示词与剪辑卡点逐字引用
6. **动作文法**：锁定打斗子包后，分镜每镜的「运镜」「唯一动作」按子包的攻防密度与镜头跟打法取值，兵器接触与受击余态按
   `$short-drama-storyboard` 的「肢体互动手艺」（`physical-interaction-craft.md`）第五节写；
   变速点（升格/降格）一律记进剪辑单 `- 后期：` 行，**不写进视频提示词正文**——生成模型没有速度概念，
   包内出现"慢镜"字样时读作"本包倾向在命中帧升格"，由剪辑层执行
7. **复刻既有打戏时**：文本层（小说）不受 §2 约束；进入视觉设定、图片/视频提示词与剪辑单时，
   角色名、演员相貌、片名、标志性台词与可识别服化道一律换成原创设定的可见要素，只保留动作文法与
   可见风格（§2 红线在本场景同样成立，"某武指风格"不得作为提示词词面出现）
