# Agent Note: 分镜侧补齐三处隐性 craft 判断——光态衬托、承受者反应可读性、镜长冲突优先级

Status: implemented

## Problem

一次跨技能评估（小说创作技能 + 短剧分镜技能）发现分镜侧三处判断只存在于审查者脑中，文档没有
可操作落点：

- **光态衬托**：`lighting-craft.md` 全文是软建议，讲了分工与连续性，却没有一条讲剧情转折时光如何
  跟着动。评估点名的「剧情变化带来场景衬托」维度在分镜侧几乎空白，而上游小说技能同维度同样最弱，
  两端接不上。
- **承受者反应**：`SHT-27` 说「按后果能否被理解判断，不按人数、景别或数量」，判据全交给审查者
  主观，没有检查步骤，也没有「什么算过度、什么算不足」的正反例；与 `keyframe-craft` 「每帧写一个
  可读状态」在「不补反应镜」时如何共存，没有衔接。
- **镜长冲突**：对白估时说「取容得下时间线的合法时长、不删词不改快读」，`SHT-28` 说「明显长于目标
  先补反应镜、明显短于目标合并切点」，但两者冲突时（时间线推出 12s、target × 镜数只有 8s）谁优先，
  散在两节里没有一句裁决。

## Decision

三处都按「把隐性判断显性化」增补，不新增数值门槛、不新增模型特定配方、不加跨技能链接，也不改
`stage-contract.md` 的规则定义表：

- `lighting-craft.md` 新增「光态随剧情变化（衬托）」一节（craft_default）：同一光源身份与方向不变
  （承接 SHT-12、CON-02），随剧情只动注意中心（谁在明区/暗区）、光比与色温的相对关系、被照亮的
  是脸还是证据；给「剧情节点 → 光态投影」对照与反面（光源跳变、无来源轮廓光按 CON-02 判漂移）。
  与小说技能 content-expansion 的「剧情状态 → 氛围载体映射」同构，让上下游能对齐。
- `shot-craft.md` SHT-27 补「可读性三步」通用检查（找承受者 → 静照能否读出被打中 → 载体是否匹配
  景别）、不补镜时把后果投影进同镜起终点面部读数的衔接、以及不足/过度两个正反例。过度一例显式引
  production-shot-grammar「保持不动也可能是有效表演」，守住 model-scoped 笔记定的「不外推反应
  配方」边界——模型特定配方仍归视频提示词。
- `shot-craft.md` SHT-28 后补一句冲突优先级：时间线是本场必须容下的下界（硬），target_avg 是场级
  平均目标（软、非每镜配额）；冲突时时间线优先，用拆镜/补反应/合并无信息切点消化，不删词、不改
  快读，集长或原生时长放不下时交创作者定，与 project_tool status 的 profile_notes 定档提示一致。
- CHANGELOG [Unreleased] 新增 Added 一条登记三处（craft/reviewed 判断显性化，非收紧、非纯排版）。

## Alternatives considered

- **给光态衬托引入光比/色温数值门槛（如「转折处光比≥2:1」）**：最强理由是机械可查、审查客观。
  未采用：违反 AGENTS.md 硬规则 3「不得把统一的字数、比例、数量配方设为质量门槛」，且光比随题材、
  画幅、模型差异极大，数值门槛会逼出假精确。改为选择判据 + 对照 + 反面。
- **把承受者反应可读性升成 structural_invariant 让检查器校验**：最强理由是能机械阻断漏反应的镜头。
  未采用：可读性是「观众能否理解后果」的语义判断，检查器只能验字段存在、验不出可读；强行结构化会把
  审查 verdict 冒充成机器结论，违反「所有权与审查分离」。保留 reviewed_invariant，只补检查步骤与正反例。
- **给对白估时与 SHT-28 的冲突加一个自动裁决脚本**：最强理由是省人工、结果一致。未采用：冲突的解法
  （延长/拆镜/多镜容器/剧本修订）本就是创作者决定，脚本只能提示不能代选；timing-chain 笔记已把这类
  冲突放进 status 的 profile_notes 提示，文档层补优先级即可，不重复造机制。

## Consequences

- **收益**：三处原本靠审查者个人经验的判断有了可操作落点；光态衬托与上游小说技能对齐，贯通了
  「剧情 → 氛围」这条产线最弱的链。
- **代价与局限**：全部是 craft/reviewed 判断的显性化，**没有新增任何生成实验或盲评**，不把文档增补
  冒充成模型效果验证（与 model-scoped-reaction-default 笔记的诚实边界一致）；光态对照表是起步默认，
  实际以目标模型出图为准。增补只落在 short-drama-storyboard 目录与仓库根的 CHANGELOG、本笔记，
  未改 SKILL.md 工作流、字段、规则定义表或脚本。
