# 质量检查清单

交付章节前使用此清单确保质量。

## 整体检查

### 基础要素

- [ ] **章节有明确标题**
  - 标题与内容相关
  - 吸引人但不过度透露

- [ ] **字数符合预期**
  - 短章节：800-1500 字
  - 标准章节：1500-3000 字
  - 长章节：3000-5000 字

- [ ] **章节完整性**
  - 有开头、发展、高潮
  - 不是片段，是完整叙事单元

- [ ] **时间地点清晰**
  - 读者知道何时何地
  - 转换时有明确标记

---

## 开头检查

- [ ] **前 3 段内抓住读者**
  - 有行动/冲突/悬念
  - 不是天气或日常流程

- [ ] **与上一章有连接**
  - 回应上一章结尾
  - 或明确时间/地点跳跃

- [ ] **背景信息不过量**
  - 没有大段信息倾倒
  - 信息自然融入动作

---

## 内容检查

### 情节推进

- [ ] **本章有核心事件**
  - 发生了不可删除的事
  - 不是"什么都没发生"的过渡章

- [ ] **推动主线剧情**
  - 揭示新信息
  - 或改变人物关系
  - 或升级冲突

- [ ] **逻辑自洽**
  - 事件因果关系合理
  - 没有巧合驱动剧情
  - 人物行为符合动机

### 冲突与张力

- [ ] **有明确冲突**
  - 人与人、人与环境、人与自己
  - 冲突推动本章事件

- [ ] **张力有变化**
  - 不是平铺直叙
  - 有紧张和缓解的交替

- [ ] **有转折或新信息**
  - 不是线性可预测
  - 有意外或新发现

---

## 人物检查

- [ ] **人物行为一致**
  - 符合已建立的性格
  - 如不一致，有解释

- [ ] **人物有反应**
  - 对事件有情绪/行动
  - 不是被动道具

- [ ] **人物有声音**
  - 对话能区分角色
  - 每人说话方式不同

- [ ] **人物展示而非讲述**
  - 通过行动/对话表现性格
  - 不是直接陈述"他很勇敢"

---

## 对话检查

- [ ] **每句对话有目的**
  - 推动情节/揭示人物/制造冲突
  - 没有"你好""吃了吗"等无意义对话

- [ ] **对话简洁自然**
  - 删除冗余词语
  - 符合真实说话方式

- [ ] **有潜台词**
  - 不是所有话都直说
  - 有言外之意

- [ ] **标签使用正确**
  - 能辨识时省略标签
  - 不过度使用副词

- [ ] **可检查的对话硬指标**（能逐条数出来，不靠感觉）
  - 连续裸"他说/她说"（无任何动作或表情）不超过 2 回合
  - 单场对话里，删掉后不影响情节/人物/冲突的"废话句"为 0（寒暄、复述已知信息）
  - 没有"信息倾倒"句：人物不会互相讲双方都已知的背景（"正如你所知，我们公司成立于……"）
  - 每个主要角色的台词，遮住名字后仍能凭用词/句式/口头禅认出是谁（声音区分）
  - 副词修饰的对话标签（"愤怒地说""高兴地问"）改为动作或留白，全章不超过 2 处

---

## 悬念检查

- [ ] **结尾有钩子**
  - 使用至少一种悬念技巧
  - 让读者想看下一章

- [ ] **悬念强度适当**
  - 与故事位置匹配
  - 高潮章节悬念更强

- [ ] **不是虚假悬念**
  - 不是机械误会
  - 不是无意义的"突然"

- [ ] **为下一章铺垫**
  - 设置下一章的冲突
  - 埋下伏笔

---

## 展示而非讲述检查

### 常见"讲述"标记

检查并修正以下模式：

| 讲述（避免） | 展示（使用） |
|-------------|-------------|
| 他很愤怒 | 他握紧拳头，指节发白 |
| 她很美丽 | 他凝视着她，忘记说话 |
| 他很紧张 | 他反复调整领带 |
| 房间很乱 | 衣服扔在沙发上，外卖盒堆在桌上 |
| 他很富有 | 他从口袋里掏出一叠现金 |

### 自查问题

- [ ] 是否直接陈述情绪？（改为身体反应）
- [ ] 是否用形容词总结？（改为具体描写）
- [ ] 是否跳过了关键场景？（补充展示）

---

## 节奏检查

- [ ] **句子长度有变化**
  - 没有连续 3 句长度相同
  - 长短交错

- [ ] **段落长度适当**
  - 避免大段文字墙
  - 动作场景用短段落

- [ ] **信息密度有变化**
  - 高密度（动作/对话）
  - 低密度（描写/内心）

---

## 细节密度检查

- [ ] **表情锚定**
  - 每个对话回合至少一个可观察的表情/微表情变化锚定语气
  - 没有连续两轮裸"他说/她说"（无任何脸上或手上的动静）
  - **例外（防过度）**：以下情形可裸标签、不强制补表情，硬补反而是新的 AI 味——
    - 快速交锋的短对话（你来我往的斗嘴、审讯逼问、报菜名式信息交换）
    - 纯信息型台词（报时间、报地点、念数字），情绪不在这一句上
    - 已经用动作替代标签的回合（"她拍案而起"已经承载了表情，不必再加"她愤怒地"）
  - **只在情绪转折点强制锚定**：支点事件、态度反转、谎言被戳破的那一句，脸上那一下不能省
  - **反面示例（过度微表情，需删）**：
    > "我知道了。"他嘴角微微上扬，眼中闪过一丝不易察觉的复杂情绪，手指无意识地摩挲着杯沿。
    > ——三个微表情叠在一句平淡台词上，属于注水；留一个最相关的即可，或干脆裸标签。

- [ ] **场景切换桥**
  - 章内场景切换有桥接行（感官残留/声音延续/母题物件/光线变化），不裸跳
  - 分隔符只出现在桥接行之后

- [ ] **支点事件演出**
  - 分手、摊牌、告别、背叛、抉择等主要情感转折写成演出的场景（地点、回合、可见变化）
  - 没有把支点事件压缩成一句转述；转述只用于余波

- [ ] **动作段可拍因果**（对应 SKILL.md 三大黄金法则第 4 条；只查有打斗/追逐/抢夺的章）
  - 每一处接触都写清打击点、发力方向、承受者的重心变化
  - 每次接触后有一个可见结果（位移、防守被破坏、呼吸或表情失控）；两次接触之间没有空白代价
  - 没有"激烈交手""缠斗良久""大战三十回合""一番苦战"这类无法被读者看见的概括
  - 关键动作没有被"缓缓、慢慢、轻柔、徐徐"这类减速修饰包住
  - 速度靠短句与短促动词（劈、搡、错、卸、绊）承担，不靠"极快""迅猛"这类形容词声明
  - 多人混战：先有主角的背靠面（背后靠什么、哪侧安全）与当前对手；其余人只写"此刻在做什么"，
    不给每人一段独立战斗
  - 换对手有可见触发（听见背后脚步、前一人倒下），不用"他又迎上另一个人"这类无因由接替
  - 本章无打斗/追逐/抢夺时整节跳过，不为了打勾补写动作

## 语言检查

- [ ] **没有 AI 写作痕迹**

  - 避免四字成语堆砌
  - 句式多样化

- [ ] **"的"字不密集**
  - 没有连续多个"的"
  - 简化修饰结构

- [ ] **用词精确**
  - 避免模糊词（"一些""某种"）
  - 使用具体词汇

## 量化去 AI 味指标（脚本可数，不代替判断）

`python scripts/check_text_metrics.py <章节文件.md>`（或 `--all <目录>` 递归分卷）统计下面这些
**数得出**的项，退出码 0=在阈内、1=有超阈、2=用法错误；加 `--report-only` 只报告不判。
默认阈值按每千字归一，可用参数覆盖：

| 可数项 | 默认上限 | 超出时怎么改 |
|---|---|---|
| 比喻标记（像／如／仿佛／宛如／犹如／好似／似乎／般／一样） | ≤3 处/千字 | 留最准的那个，其余改成具体动作或物象；比喻不是修辞配额 |
| 破折号 | ≤2 处/千字 | 拆句或改用逗号；成对使用时尤其检查是否真需要停顿 |
| 连续三句字数几乎相同（差 ≤2） | 0 组 | 打散：换一句长度、并句或断句，让长短交替成呼吸 |
| 连续三段行数相同 | 0 组 | 改变段落形状，别把全文排成一样高的方块 |
| 裸对话标签占比（他说／她说／或裸套话） | ≤25% | 多数换成可观察的动作或物件；判定口径见下方「裁决一」 |

排比是否成立、意象是否准确、留白是否有效——这些需要人判，脚本不数也不假装数。

### 裁决一：表情锚定与微表情套话（2026-10-30 定）

**两者的冲突是假冲突**：`SKILL.md` 第 11 步要求的是「有可观察的变化」，外部去 AI 味资料禁止的是
「用套话填空」。真正该改的是把**表情**当成了唯一锚定单位。裁定如下：

1. **锚定单位放宽，套话计为零。** 每个对话回合需要一个可观察的变化，但合格形式包括：
   动作、物件、身体位移、距离、沉默或停顿、呼吸、语气与用词的变化、话题转向。
   单靠「表情」一项完成的锚定本就最弱，套话式表情更是零信息。
2. **以下命中判违规（不是提示）**：嘴角勾起一抹、勾起一抹、眼底闪过、眸中闪过、眼中闪过、
   瞳孔骤缩、眉头微蹙、眉头紧锁、心中一凛、心中一动、不由自主、深吸一口气、狠狠地、
   清晰地看到、深深地看了。它们是填空而非观察，删掉后句子里什么都不剩。
3. **可核对的判据**：把该回合的套话短语整段删掉，若回合内不再有任何可观察变化，
   就是裸回合——计入上面的裸对话比例。删掉后仍有动作或物件在动，则不算问题。
4. **三类豁免**（须成立才免，默认不豁免）：
   - 刻意压住的静止：对峙段里人物就是不变，且这份静止在下一回合被改变或被写进代价；
   - 第一人称受限视角：叙述者只能报告内部反应，按 `style-era-guide.md` 的 POV 纪律执行；
   - 文风档明选「古典白描／零度叙事／冰山体」且以克制为目的——须在 `00-大纲.md`
     的「风格约定」里写明该选择，未写明的按违规处理。

### 裁决二：「缓缓／慢慢／轻轻」与比喻词的档位（2026-10-30 定）

**不一刀切禁用**，按它修饰的是铺垫还是关键接触来分档；同时把两类常被混为一谈的词拆开：

1. **判违规**（三选一命中即判）：
   - 关键接触所在句内出现减速词——同一句里既有 缓缓／慢慢／轻轻／徐徐，又有接触动词
     （劈、斩、刺、扫、撞、削、磕、格、落刀、落剑、击中、命中、撞上、压下）：
     力量感正是在这一拍被抹掉的；
   - 连续两句都带减速词：节奏被拉平成腔调；
   - 一章内铺垫类减速词超过 4 处：不再是选择，是口癖。
2. **只提示不判**：单个减速词修饰铺垫类动作（抬手、推门、走近、落座、转身、放下），
   尤其庄重、哀恸、反讽或镜头感的语境——这类确实是风格，禁用它属于误伤。
3. **比喻词另走密度**：仿佛／似乎／宛如／犹如／好似／像／如／般／一样 按上表第 1 行的
   千字密度处理，**不列入减速词禁项**，也不单独当禁词。两派资料把它们与「缓缓」混在一起谈，
   是这条口径最容易出误判的地方，特此分栏。
4. 想退回全不判（例如风格实验章）时用 `--report-only`；想加严就降
   `--slow-contact-zero` 之类的阈值参数，方向由你调，规则本身不再含糊。

**脚本已按以上两条接入判定**：`check_text_metrics.py` 里套话命中与「关键接触被减速」计入退出码 1，
铺垫类减速与连续度提示保留为说明行。改动这两条判定时，同时改本节与脚本的对应阈值即可。
