# 人物档案 → 短剧视觉设定 映射模板

把 `01-人物档案.md`（心理向）翻译成 drama-skills 的 `视觉设定.md`（视觉向）条目。
**语义不同，不能直接搬**：档案管"性格/动机不漂移"，视觉设定管"服装/外形不漂移"。

## 映射规则

| 人物档案字段 | 视觉设定字段 | 翻译要求 |
|------------|------------|---------|
| 姓名 | `## 人物 · [姓名]` 条目名 | 直接用 |
| 外貌特征 | **识别锚点** | 必须扩写到出图级：脸型、眉眼（眼型/瞳色）、鼻、唇、肤色、发型（长度/卷直/颜色/打理方式）、永久性身体特征。写"可见的、跨镜不变的"事实 |
| 年龄/职业 | **本集造型**（Look） | 职业→服装剪裁与材质；年龄→妆面与状态。写当前集的完整从头到脚 |
| 背景故事 | 状态变化（可选） | 只有造成**可见永久痕迹**的背景才进锚点（如旧伤、胎记）；其余不进 |
| 性格核心/MBTI | 不进入视觉设定 | 通过 `图片提示词.md` 的气质载体（表情/站姿）间接体现，不写成锚点 |
| 标志性配饰（如有） | **连续性锁** | 凡跨镜出现、观众看得出不一致的配饰必须上锁：`LOCK-XXX《名称》（镜头：…；图片提示词项：IMG-…）· 锁面：[逐字短语]` |
| （新增） | **画面代称** | 提示词正文里直接叫到这条的名字；提示词语言非中文时必须声明 |
| `02-世界观` 的 `LOC` 条目 + 场景模板里的**感官锚点** | 视觉设定 `## 地点 · [名称]` 的**固定锚点** | 地理锚点（入口、分区、方位）必写；感官锚点要拆成两栏：**可复现的**（哪扇窗朝哪、哪个位置有汽笛、哪盏灯常亮）进锚点，**纯形容**（"压抑""潮湿得让人心慌"）删掉。前者是下游写"光态/声响随剧情变化"的唯一依据 |
| 场景模板里跨章复现的**母题物件**（旧戒指、翻毛页角、半截肠衣） | 视觉设定 `## 道具 · [名称]` 的**识别特征 + 状态序列** | 不要只写名称。写可数或可辨的特征（磨损在哪个角、内壁刻痕深浅、数量）与每次出现时的状态差异。母题物件没有功能，因此不写启用次数与消耗，这两栏属于功能道具 |
| 场景模板里的**母题物件**同时要交下游时 | 分镜 `- 母题：` 行的取词来源 | 分镜行要求"特征可数/编号/磨损"，取词必须与视觉设定逐字一致；两处不一致时以视觉设定为准，因为资产是唯一登记处 |
| 纯背景陈设 | 不进入视觉设定 | 按布景处理；只有被角色拿起、传递、读取或反复出现时才升级为道具条目 |

**地点与道具这两行是补充项，不替代人物映射**：`01-人物档案.md` 仍是人物条目的唯一来源，
地点与道具从世界观文件和场景模板来。三者都没有对应字段时，宁可留空也不要凭空补一条
"标志性场景"——凭空补的锚点下游会当成既有事实沿用。

## 翻译示例

输入（人物档案.md）：
```markdown
### 林雨
- **年龄/职业**：24 岁，大学美术生
- **外貌特征**：好看，有气质
- **性格核心**：坚韧不拔
```

输出（视觉设定.md）：
```markdown
## 人物 · 林雨
- 识别锚点：鹅蛋脸、内双眼皮、左眉尾小痣、及肩黑直发中分、左腕旧烫伤疤。
- 本集造型：洗白牛仔裤、 oversize 米色卫衣、白色帆布鞋，头发半扎。
- 状态变化：无。
- 画面代称：Linyu
- 连续性锁：LOCK-LINYU-HAIR《林雨及肩黑直发中分》（镜头：入画；图片提示词项：IMG-LINYU-BOARD）· 锁面：shoulder-length straight black hair with center part
```

## 出图排版（角色参考板）

翻译完成后，人物主资产出图一律使用
`drama-skills/short-drama-image-prompts/references/character-reference-board.md` 的
**影棚模特卡三段式**：左侧主视图特写（85mm 浅景深）+ 右上正/侧/背三视图全身横排
（全身入镜含脚部鞋子地面）+ 右下五格表情板（平静/微笑/害羞/难过/惊讶），
横向构图、浅灰无缝影棚背景、细净分割线、所有分格打光一致、每一格同一张脸。
锚点全部取自本条目，不得臆造。
