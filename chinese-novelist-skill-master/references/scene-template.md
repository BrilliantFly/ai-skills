# 场景设定模板

`02-场景设定.md`：全书场景/地点/环境的**唯一事实来源**。人物不漂移靠人物档案，
场景不漂移靠本文件。规划阶段与人物档案一起生成，逐章创作时先查此文件、新地点
首次出现时补登。

## 使用规则

1. **规划阶段**：按大纲"世界观与年代设定"的地理与主要场景清单，为主要地点各建一节
2. **逐章创作**：写前分析规划场景时，本章场景必须取自本文件；需要新地点时**先补登、后动笔**
3. **写后收尾**：更新各地点的"出现章节"索引；感官锚点有新增也回写
4. **下游改编**：进入 drama-skills 产线时，本文件按地点逐条映射到 `视觉设定.md` 地点条目，
   并对接 `short-drama-image-prompts/references/location-plate.md` 出地点板
