# 可渲染对白（影视化台词约束）

小说默认写给读者看；一旦要送进短剧产线（`drama-skills`）变成镜头，台词就同时是**音频轨的生成输入**。
本文件只管一件事：**让写出来的每句台词都能被单轨生成模型念对、并且能被拆成镜头**。

不改变文学判断，只加六条下限。纯文学创作、不打算改编时整份跳过。

## 为什么需要这一层

生成模型的对白是「一条音轨、一个说话人、一段连续发声」。它做不到三件事：

1. 在同一个镜头里分派两个人的音色（同框双人对话 → 音轨塌成一条，谁都不像）；
2. 把一句 30 字的话念清楚（超过约 15 字，清晰度断崖下跌，常念成同音乱码）；
3. 在一个镜头里同时处理「三个时间点 + 两句台词 + 一个动作」。

所以问题不在文笔，在**台词与镜头的匹配形态**。小说层提前把形态摆正，下游不用返工。

## 规则一：台词预算

| 项 | 上限 | 说明 |
|---|---|---|
| 单句字数 | **6~12 字**（硬上限 15） | 按约 4~5 字/秒估算，12 字约占 2.5~3 秒发声窗口 |
| 单镜台词句数 | **≤ 2 句** | 一句一镜最稳；两句必须是同一说话人 |
| 单镜说话人切换 | **≤ 1 次** | 首选 0 次。切换一次意味着要拆成正反打 |
| 打斗喊招 | **一回合只喊一个招名**（2~4 字） | 不同时喊、不连喊、不喊整句 |

**超限处理**：不删戏，改**断点**。把长句按语义断成两截，中间留一个不需要说话的动作位——
对手的反应、一次兵刃相击、一个转身——这个动作位在下游正好落成一个 0.5 秒的反应镜。

```text
改前（29 字，一句，模型必糊）：
「前辈这刀虽是扶桑形制，可刀上刻的字分明是中土的字，前辈到底是谁？」

改后（两镜，中间留一个可拍的反应位）：
「前辈这刀，是扶桑的形制。」        ← 8 字
（对手眼睛在纱后动了一下）           ← 反应镜，无台词
「可刀上的字，不是扶桑的字。」        ← 12 字
```

## 规则二：招式念名与打斗描写解耦

写出招必须**一回合一方、一回合一名**：

```text
回合制写法（可拍）：
回合 1  令狐冲出剑，喊「荡剑式」  → 向问天横刀格挡，退半步
回合 2  向问天反劈，喊「断流」    → 令狐冲侧身，剑尖挑开刀背
回合 3  令狐冲变招，喊「撩剑式」  → 向问天刀势已老，被迫换手

非回合制写法（文字燃、镜头废）：
令狐冲连喊「荡剑式」「撩剑式」「落剑式」，向问天也喝出「断流」「破刀」，
两人在同一个画面里越打越快……
```

后者的每一句都要求「同框两人同时开口」，落到生成端就是空音轨。前者每一回合都能独立成为
一个单人镜或过肩镜，喊招的人和接招的人永不同框发声。

**收尾自检**：一段打斗里，任何两句不同说话人的台词之间，是否至少隔着一个可见动作？
不是的话，把动作补进去，或者把台词并给同一个人。

## 规则三：为「可拆镜」而写

打斗与对峙不要写成「两人在同一个画面里缠斗」，要写成可拆的连续动作段落——每一段都满足
「一个主体 + 一个动作 + 一个可见结果」，这种句子才拆得出单人正反打。

| 拆不出来（同框绑定） | 拆得出来（单人可承载） |
|---|---|
| 两人贴身缠斗，刀剑交击不断 | 令狐冲递剑，向问天横刀架住；刀背一沉，令狐冲手腕下沉三寸 |
| 二人在亭中对峙良久 | 令狐冲的剑尖停在离对方咽喉一寸处；向问天没眨眼 |
| 众人围上来，他环顾四周 | 第一个扑上来的人被他侧身让过；第二个停住脚步 |

写完后在本场末尾补一行拆镜建议（给下游看的，不是正文）：

```text
- 拆镜建议：本场可拆 9 个单人镜（令狐冲 5 / 向问天 4）、3 个过肩镜、1 个空镜；无同框对话镜
```

## 规则四：避开发音会糊的字

生成端咬字本来就弱，字幕级准确的台词它念不出来。这不是文笔问题，是要在写作时避开的地雷：

| 要避的 | 原因 | 改法 |
|---|---|---|
| 生僻字（`缶`、`隼`、`镡`） | 模型多半念成近音或吞掉 | 换常用字，或用动作/道具代替 |
| 多音字歧义（`重`、`行`、`长`、`了`） | 无上下文时随机取音 | 换词：`重` → `又`；`了` → `过` |
| 三字连读同韵（`荡剑式`、`破刀式`） | 三个字糊成一坨，谁都听不出 | 喊招写 2 字（`荡剑`）或让动作承担 |
| 单字回应（`嗯`、`哦`、`是`） | 时长不足，被噪声吞 | 补成有信息量的短句（`是我。`），或改由动作/眼神承担 |
| 半句（`你这——`） | 断句落在逗号上，模型补不出后半 | 要么写完，要么不写 |

一句话：**能让动作说清的，不要交给嘴。**

## 规则五：每句台词标「发声窗口」

下游要按这句台词算镜长。你只给字数，它只能猜。写清三个数：

```text
字数 12 / 预计 3.0 秒 / 开口前留白 0.6 秒
```

- 语速按 **4~5 字/秒**，宁慢不赶。12 字按 3 秒算，8 字按 2 秒，4 字按 1 秒。
- 「开口前留白」= 人物先有一个动作或一个眼神，再开口。无留白时口型会从第一帧就开始动，接不上前一个镜头。
- 这两项决定了这一镜能不能装进最短档（约 4.5 秒）。装不下就**拆成两镜**，不要压缩语速，也不要写「快速说」。

## 规则六：每句标「可删等级」

对白在生成端有失败率。写的时候就把退路留好，别等全片报废才发现删无可删。

| 等级 | 含义 | 处置 |
|---|---|---|
| `必需` | 删了剧情接不上 | 出问题必须保住，宁可 TTS 补配 |
| `可删` | 删了剧情仍通，只是少一层味道 | 对白不达标时直接删掉，改成动作或反应镜 |
| `点缀` | 纯气质、可有可无 | 优先删 |

目标：`必需` 不超过全部台词的 **60%**。一部 20 句台词的短集，至少留 8 句可以无声删掉，
这样"对白层不可用"才不至于变成"整片重做"。

## 规则七：台词带元数据，并输出清单

正文里的台词保持自然（不要写进正文），但每章结束时另出一份**机器可读清单**。
这是 novelist → drama 的唯一数据契约，下游据此建镜头、绑音色、算镜长，不再从散文里正则抠台词。

`对白清单.csv`（与章节同目录，UTF-8）：

```csv
场次,镜序,说话人,台词,字数,预计秒数,留白秒,情绪,建议镜型,是否念招,可删等级
SC001,1,令狐冲,前辈这刀，是扶桑的形制。,12,3.0,0.6,压着火,SOLO,否,必需
SC001,2,令狐冲,可刀上的字，不是扶桑的字。,12,3.0,0.4,更轻,SOLO,否,可删
SC002,5,令狐冲,荡剑！,2,1.0,0.3,断喝,SOLO,是,可删
```

- `建议镜型`：`SOLO`（单人面向镜头说话）/ `OTS`（过肩，仅一人发声）/ `DUO`（双人同框，**不带台词**，只作反应或环境声）。
- 出现 `DUO` 且填了台词，即为本文件定义的**错误**：要么改镜型，要么把台词分给另一个人、另起一镜。
- `是否念招` 为「是」时，该句不进对白预算统计，按喊招处理（2~4 字、一击一名）。
- `预计秒数`、`留白秒` 供分镜算镜长用；下游不得自行改写这两个数，只可因装不下而拆镜。

## 检查清单

- [ ] 每句台词 ≤ 15 字，常用 6~12 字
- [ ] 单镜 ≤ 2 句，且同一说话人
- [ ] 不同说话人的台词之间，至少一个可见动作
- [ ] 打斗一回合只喊一个招名
- [ ] 没有生僻字、多音字歧义、三字连读同韵、单字回应、半句话
- [ ] 每句都标了 `预计秒数` 与 `留白秒`
- [ ] `必需` 级台词 ≤ 60%
- [ ] 每场末尾有拆镜建议，无「同框对话」这种拆不出来的写法
- [ ] 已输出 `对白清单.csv`，`DUO` 行没有台词
