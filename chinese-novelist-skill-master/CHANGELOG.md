## [Unreleased]

### Added

- 武侠文字呈现：新增 `references/wuxia-prose.md`（出招节奏与接触四结果、代价与重量五层账目、
  身法与空间、视角与旁观分层、古典语感的可执行部分、章的推进与收束、自检 8 条）。文件头写死三条边界：
  不碰镜头与攻防相位（归短剧分镜层，与既有「小说层不预先限制镜头」口径一致）、`SKILL.md` 第 5.7 条
  是检查项而本文是写法来源、力量与师承取值一律来自大纲不得临时发明。内容按武侠通行写法自拟，
  **未参考任何外部技能包正文**，因外部唯一的武侠成体系资料受 AGPL/GPL copyleft 约束（见下条）。
- 设定承载位补三处（均为可选，非武侠题材整节忽略）：`outline-template.md` 新增「力量体系与门派谱系」
  小节（力量体系四栏代价表／门派与势力／辈分与师承／兵器武功命名规矩／江湖规矩与禁忌），
  伏笔账本补「分卷时追加『卷』列并按卷清账」的说明；`character-template.md` 新增武功与力量、
  惯用兵器、师承与辈分、身法签名四个可选字段。既有列名、列序与九个原字段未动。
- 量化去 AI 味：新增 `scripts/check_text_metrics.py`（比喻与破折号每千字密度、连续三句字数是否相同、
  连续三段行数是否相同、裸对话标签占比，阈值可覆盖，`--report-only` 只报告；退出码 0/1/2）。
  `quality-checklist.md` 补「量化去 AI 味指标」一节；微表情套话与「缓缓/慢慢」两类**只报告不判违规**——
  它们与 `SKILL.md` 第 11 步的表情锚定要求存在口径冲突，未由工具代创作者裁决，待定向后再接入判定。
- 许可与索引：补 `LICENSE`（MIT 全文，此前 README 徽章指向的 LICENSE 为死链、许可证只以正文一行存在）；
  README「内置参考资料」表补 `scene-template.md`、`style-era-guide.md`、`visual-settings-mapping.md`、
  `wuxia-prose.md` 四行（原表漏列既有三份）。

- 视觉设定映射补地点与物件两行：`references/visual-settings-mapping.md` 的映射表新增「世界观 LOC +
  感官锚点 → 地点固定锚点」（地理锚点必写、感官锚点拆成可复现与纯形容两栏、纯形容词删掉）与
  「跨章复现的母题物件 → 道具识别特征 + 状态序列」（不写启用次数与消耗，那属于功能道具），
  并补「纯背景陈设不进视觉设定」与「三处都没字段时宁可留空」两条边界。此前该表只映射人物外貌，
  小说在场景模板里登记的感官锚点与母题物件没有通道进视觉设定，改编时到不了剧本与资产。
- 交付前清单补动作节：`references/quality-checklist.md` 的「细节密度检查」新增「动作段可拍因果」
  8 条勾选项（打击点/发力方向/重心变化/可见结果/不可见概括/减速修饰/多人混战背靠面/换对手触发，
  无打斗章整节跳过），并行在「类型特定检查 · 动作类」补一条指回该节的确认项。此前第 4 条规则只
  写进 `SKILL.md` 与两处 references，写作时有、交付时无对应勾选项，属检查清单盲区。SKILL.md 未改，
  仍为 6774 字，避免继续膨胀。
- 动作段写法：「细节密度」追加第四条（打击点+发力方向+重心变化+可见结果；速度由短促动词承担，
  关键动作不加减速修饰；多人混战先定背靠面与当前对手，其余人只写状态）；`chapter-guide.md` 高潮
  时刻补「动作高潮的写法」（换对手要有可见触发，禁"缠斗良久""大战三十回合"这类概括）；
  `content-expansion.md` 校正"动作场景的分解"的含义——拆因果链而非拉长时间，长句慢描写会让场面
  发软并连带下游写成慢节奏指令。只管文本可拍，招式拆镜与同时动作句式归短剧视频环节。
- 产线衔接补第 5 步「改编适配建议」：母题物件转成剧本母题条目与分镜 `- 母题：` 行、靠分隔符跳过的
  场景切换先补转场桥、内心独白在剧本「声音分层」一次定死 `[VO]` 或画内对白、动作段写成可拍因果链
  后拆镜交下游。
- 逐章流程新增 5.7 中期动作段自检：每逢 5 章扫描打斗/追逐/抢夺段的不可见概括、减速修饰与
  无结果的接触，发现即改写。

- 「细节密度三规则」（表情锚定 / 场景切换桥 / 支点事件演出）：`SKILL.md` 三大黄金法则下新增正文规则，
  `references/quality-checklist.md` 新增「细节密度检查」节（9 个可勾选项），逐章创作流程新增
  5.6 中期细节密度自检（每逢 5 的倍数章与中期自检同批静默执行）。针对三类盲区：对话回合连续
  裸"他说/她说"、章内场景切换靠分隔符裸跳、分手/摊牌等支点事件被一句转述带过。规则与下游
  短剧产线（drama-skills 的表情投影、氛围衬托、支点场自检）对齐。
- 「剧情状态 → 氛围载体映射」（`references/content-expansion.md`）：先定剧情状态再选已登记的
  场景锚点去改它，附「衬托三不」（不改锚点身份、不每场烘托、不直白点破）与跨章锚点演变示例；
  `chapter-template.md` 同批小改（字数说明与 `check_chapter_wordcount.py` 阈值对齐；改前无快照，
  逐字差异不可追溯）。此两项来自 2026-10-27 的跨技能评估实现，实现笔记见
  drama-skills-main `.agents/notes/implemented/feature/2026-10-27-storyboard-craft-judgment-supplements.md`——
  该笔记的范围声明未覆盖 novelist 侧文件，特在此补记以正追溯。

### Fixed

- 字数口径两处对齐：`SKILL.md` 第 9/12 步强制「每章 3000-5000 字、低于 3000 必须重写」，而
  `quality-checklist.md` 给的是短章 800-1500／标准 1500-3000／长篇 3000-5000 三档，
  两处从未按同一档位模型衔接，实际执行时按长篇档压过短章稿。现补「档位口径」说明：
  按大纲声明的档位取阈值；创作者明确要求不限字数时传 0 只统计不判不足。
  **两处原文一字未删**，靠新增的衔接说明消解冲突，不是改写规则。
- 初始化问题数漂移：README「效果展示」一处写「7 问逐一确认」，同段示例与另一处均为 8 问
  （此前 CHANGELOG 无 5 问→8 问的变更条目可查）。改为 8 问。
- `scripts/check_chapter_wordcount.py`：① 无论结果如何退出码恒 0，失败的章节在流水线里被当成通过
  ——现返回 0 达标／1 有不足／2 用法或路径错误；② `--all` 只 glob 顶层 `第*.md`，
  分卷目录里的整卷被静默跳过——现改为递归查找（跳过以点开头的文件）；③ 阈值传 0 表示只统计不判定。
- `scripts/merge_novel_to_source.py`：合并原著时整文件拼接，把 `chapter-template.md` 规定的
  `## 本章概要`（核心事件／承接上章／悬念钩子）与 `## 章节备注`（本章悬念／下章预告／伏笔标记）
  一并当成正文写进 `输入/原著.txt`。下游 `short-drama-novel-analyze` 按行号抽情节点与质感细节，
  这些元数据会伪装成原文污染分析结果。现优先取 `## 正文` 一节，无该标题时退而删除已知元数据小节，
  其余原文保留。**分卷目录仍不递归**（章号在不同卷重复，按数字排序会交错），需要时按卷分别合并。
- README 徽章指向的 `LICENSE` 为死链（仓库内不存在该文件，MIT 只写在正文一行）：补 `LICENSE` 全文。
  版权持有人暂记为 "The chinese-novelist Authors"，**待你改成期望的署名**。
