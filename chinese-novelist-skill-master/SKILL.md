**8问收集完成后**，先提炼**故事核**（不占提问名额）：
用一句话概括全书——`谁 + 想要什么 + 什么阻止了他 + 结局基调`，写入规划摘要首行，供第二阶段用户确认；此后每一章创作都必须能对回这句话。

然后进入"第二阶段：规划"。

### 第二阶段：规划 + 二次确认

执行以下步骤：

1. **创建项目文件夹**：`novels/[小说名称]/`
2. **生成大纲**：创建 `00-大纲.md`，使用 `references/outline-template.md` 模板，填入完整的章节规划，**必须包含"世界观与年代设定"小节**（依据用户选择的时代背景与地点）；
   章节规划**必须先选定结构模板** → [plot-structures.md](references/plot-structures.md)（三幕/英雄之旅/悬疑双线等），并给每章标注**节奏强度**（高潮/推进/缓和，形成全书呼吸曲线，禁止连续3章以上全高潮）
3. **生成人物档案**：创建 `01-人物档案.md`，使用 `references/character-template.md` 模板，创建主角、反派、配角档案；
   人物塑造方法 → [character-building.md](references/character-building.md)（动机-缺陷-弧光三件套）
4. **生成场景设定**：创建 `02-场景设定.md`，使用 `references/scene-template.md` 模板，为主要地点建立场景档案（空间布局、感官锚点、视觉要点）
5. **标注开篇三章**：在大纲 TODO 为第 1-3 章标记"开篇章"——第 1 章主角出场必须自带事件，3 章内必须立起核心悬念（网文留存铁律）

完成后，向用户展示规划摘要并请求确认，等待用户确认。用户同意后，进入"第三阶段：疯狂创作"。

---

### 第三阶段：疯狂创作

**重要：全程无需再次向用户确认，必须逐一章创作**

按顺序逐章创作，每章执行完整的创作流程（见下方"逐章创作"），完成一章后自动继续下一章，直到所有章节完成，
**然后自动进入"第四阶段：全书收尾"**。

## 疯狂创作——逐章创作流程

每章创作时严格执行以下步骤：

#### 1. 写前分析

1. 读取 `00-大纲.md` - 查看TODO list和已完成章节的摘要
2. 读取 `00-大纲.md` 中上一章的摘要，**并读取上一章文件末尾 200-300 字正文**——本章首段的语气、场景、人物体态必须从上一章结尾无缝续接，不得跳接
3. 更新`00-大纲.md` 中 TODO list - 将本章标记为"进行中"
4. 设计开头钩子 - **最关键**：前20%必须有即时冲突 → [chapter-guide.md](references/chapter-guide.md)（10种开头技巧）
5. 规划场景 - 确定本章需要3-5个场景，**场景必须取自 `02-场景设定.md`**；需要新地点时先按模板补登场景档案再动笔
5.5. **中期自检（每逢 5 的倍数章静默执行，不打断创作）**：对照 `01-人物档案.md`、"伏笔账本"、"世界观与年代设定"小节扫描近 5 章摘要，发现人物性格、年代细节或伏笔漂移时，先修正设定文档，漂移部分在后续章节自然回收
5.6. **中期细节密度自检（与 5.5 同批静默执行）**：对照「细节密度三规则」扫描近 5 章——对话回合连续裸"他说/她说"、场景切换靠分隔符裸跳、支点事件被一句转述带过的，回补后再继续
5.7. **中期动作段自检（与前两条同批）**：近 5 章的打斗、追逐、抢夺段，检查是否出现"激烈交手""缠斗良久""大战三十回合"这类看不见的概括、关键动作被"缓缓/慢慢"减速修饰、两次接触之间没有可见结果；发现即改写成打击点 + 发力方向 + 重心变化 + 结果
    - 武侠/玄幻题材的改法取 [wuxia-prose.md](references/wuxia-prose.md)（出招节奏、代价账目、视角与旁观、身法与空间、古典语感）；镜头与攻防相位的处理属短剧分镜层，不在小说层预判

#### 2. 撰写

6. 创建章节文件 - 使用`references/chapter-template.md` 模板
7. 撰写正文 - **每章必须达到3000-5000字**
   - 开头检查：前20%是否极其吸引人？
   - 对话规范 → [dialogue-writing.md](references/dialogue-writing.md)
   - 内容不足？使用 [content-expansion.md](references/content-expansion.md) 扩充技巧
8. 设置结尾钩子 → [hook-techniques.md](references/hook-techniques.md)（10种钩子类型）
9. **字数检查** - 必须使用脚本检查字数：`python scripts/check_chapter_wordcount.py <章节文件路径>` 低于3000字必须使用扩充技巧重写
   - **档位口径**：3000 取的是 `quality-checklist.md` 三档里的「长篇档」（短章 800-1500／标准 1500-3000／长篇 3000-5000）。本步骤与第 12 步按 `00-大纲.md` 声明的档位取阈值，两处规则按档位对齐后不再互相打架；脚本已递归查找分卷目录，退出码 0=达标、1=有不足、2=用法或路径错误，可直接当交付前的门
   - **不限字数时**：创作者明确要求不限制字数（常见于"细节越细越好"的长稿），把阈值传 0 —— `python scripts/check_chapter_wordcount.py --all <项目目录> 0` —— 只统计不判不足，扩充技巧转为按需使用，不因此重写已达意的章节

#### 3. 撰写后优化

10. 连贯性检查 → [consistency.md](references/consistency.md) - 人物一致性、情节连贯、节奏控制、**年代与场景设定不漂移（对照大纲"世界观与年代设定"小节）**
11. **深度润色（去除AI味，按叙事文风执行）** - 参照 `references/style-era-guide.md` 对应文风条目，重点检查并修改：
    - **去除过度修饰的形容词**：删减"璀璨"、"瑰丽"、"绚烂"等AI常用词堆砌
    - **减少抽象陈述**：把"心中涌起复杂的情感"改为具体动作/对话
    - **打破四字格律**：避免"心潮澎湃、热血沸腾"等陈词滥调
    - **增加口语化表达**：人物对话要有个性，避免"书面语套话"
    - **优化节奏感**：长句和短句交替，避免句式单调
    - **细节具象化**：用具体的视觉/听觉/嗅觉细节替代笼统描述
    - **先数再改**：`python scripts/check_text_metrics.py <章节文件.md>` 统计可数项（比喻与破折号密度、连续三句字数是否相同、连续三段行数是否相同、裸对话标签占比），超阈的逐处回看；微表情套话与「缓缓/慢慢」两类只提示不判——两处口径尚未定，见 `quality-checklist.md` 的量化指标一节
12. **字数检查** - 必须使用脚本检查字数：`python scripts/check_chapter_wordcount.py <章节文件路径>` 低于3000字必须使用扩充技巧重写

#### 4. 最后收尾

13. 生成章节摘要 - 在 `00-大纲.md` 添加摘要（300-500字），可附"可视化高光/收尾画面/人物状态变化"三个可选字段（模板见 outline-template.md）；本章埋设或回收伏笔时同步更新"伏笔账本"
14. 更新状态 - `00-大纲.md` 中 TODO list - 将本章标记为"完成"
15. 更新场景索引 - `02-场景设定.md` 中各地点追加"出现章节"；感官锚点有新增回写

### 第四阶段：全书收尾

最后一章完成后自动执行，无需用户确认：

1. **结局章确认**：结局章的写前分析额外执行——对照大纲"全书悬念线"，主线悬念与终极揭秘必须全部回收；"悬念承上启下"法则对结局章免除，改为**收束感**（不再留新钩子，只留余韵）
2. **伏笔清账**：核对 `00-大纲.md` 伏笔账本，未回收项必须在结局章内回收，无法回收的登记为"已放弃"并说明理由——不允许带着未处理伏笔完结
3. **全书一致性终检** → [quality-checklist.md](references/quality-checklist.md) - 对照全部章节摘要做一次跨章检查（人物弧光完整、时间线无矛盾、称谓/物品前后一致）
4. **全量字数校验**：`python scripts/check_chapter_wordcount.py --all novels/小说名/`
5. **完成报告**：向用户报告——总字数、章节数、伏笔状态（回收/放弃各多少条）、节奏强度分布；并提示下游衔接入口（`scripts/merge_novel_to_source.py` 合并原著进短剧产线、`references/visual-settings-mapping.md` 人物翻译、`02-场景设定.md` 场景直供）

## 三大黄金法则

1. **展示而非讲述** - 用动作和对话表现，不要直接陈述
2. **冲突驱动剧情** - 每章必须有冲突或转折
3. **悬念承上启下** - 每章结尾必须留下钩子

### 细节密度三规则

1. **表情锚定** - 每个对话回合至少一个可观察的表情或微表情变化锚定语气：写"她说"之前，
   先让脸上或手上有一下可拍的动静（嘴角、眉眼、指尖、呼吸）。连续两轮裸"他说/她说"即需回补；
   心理注解可以延后，脸上那一下不能省。
2. **场景切换桥** - 章内场景切换不得只靠空行或分隔符裸跳：每个切换点用一行桥接（上一场景的
   感官残留、声音延续、母题物件或光线变化），让读者从旧场景"被带"进新场景；分隔符只能跟在桥接行之后。
3. **支点事件演出** - 分手、摊牌、告别、背叛、抉择等承担主要情感转折的事件必须写成演出的场景
   （有地点、有回合、有可见的表情与动作变化），不得压缩成一句转述；转述只能用于支点事件的余波。
4. **动作段写可拍因果** - 打斗、追逐、抢夺这类场面，一次接触写清打击点、发力方向与承受者的重心变化
   （"右手劈向腕，对方手腕外翻、重心后坐半步"），不写"激烈交手""缠斗良久"这类无法拍摄的概括；
   速度由短促动词承担（劈、搡、错、卸、绊），关键动作不加"缓缓、慢慢、轻柔"这类减速修饰；
   每次接触之后必须有一个可见结果（位移、防守被破坏、呼吸或表情失控），两次接触之间不允许没有代价。
   多人混战时先定主角的背靠面与当前对手，其余人只写"此刻在做什么"，不给每人一段独立战斗。
   这一条只管文本可拍，招式拆镜、相位与同时动作的句式归短剧视频环节，不在此重复。

### 字数检查脚本

使用 `scripts/check_chapter_wordcount.py` 检查章节字数：

```bash
# 检查单个章节
python scripts/check_chapter_wordcount.py novels/小说名/第01章.md

# 检查所有章节
python scripts/check_chapter_wordcount.py --all novels/小说名/

# 自定义最小字数

```

低于3000字的章节必须使用 [content-expansion.md](references/content-expansion.md) 的扩充技巧进行扩充。

## 与短剧产线衔接（drama-skills）

本技能写完的小说可以直接进入 drama-skills 短剧产线改编：

1. **合并原著**：`python scripts/merge_novel_to_source.py novels/书名/` 生成 `输入/原著.txt`，
   交给 `short-drama-novel-analyze` 建章节索引与分集候选
2. **大纲即底稿**：`00-大纲.md` 的"章节摘要"（300-500字/章）可直接作为原著分析的追溯底稿；
   "世界观与年代设定"小节是下游 `视觉设定.md` 的地点/道具/造型直接输入
2.5. **场景直供**：`02-场景设定.md` 按地点逐条映射到 `视觉设定.md` 地点条目，对接 `short-drama-image-prompts/references/location-plate.md` 出地点板
3. **人物翻译**：把 `01-人物档案.md` 按 `references/visual-settings-mapping.md` 映射成
   `视觉设定.md` 条目（外貌特征→识别锚点，配饰→连续性锁）
4. **主资产出图**：人物图片提示词一律按 drama-skills 的**影棚模特卡角色参考板**三段式
   （主视图特写 + 正/侧/背三视图全身横排 + 五格表情板），锚点取自视觉设定条目
5. **改编适配建议**（交给剧本阶段，不自动改写）：小说里已登记的母题物件（贯穿出现的灯、叶、窗光、
   反复走的同一条路）在剧本层转成母题条目、在分镜层转成 `- 母题：` 行，转折落点优先让它入画；
   小说里靠空行或分隔符跳过的场景切换，改编前先补成一句转场桥，再决定分镜用哪种转场手法；
   小说里的内心独白段落，改编时在剧本「声音分层」里一次定死是 `[VO]` 还是画内对白，
   不让下游各环节自行改判；动作段按本技能的「动作段写可拍因果」写成可拍因果链后，
    拆镜与招式相位交给短剧分镜环节，不在小说层预先限制镜头。
6. **叙述段转旁白（第三人称画外音，不是人物开口）**：叙述者的话——交代时间地点、写人物没说出口的
   判断与情绪、跨章收束的那类第三人称叙述段——改编时默认写成剧本的
   `[VO] 旁白（男声/女声）：<小说原句>`，文案直接取原文句子，不改写成角色台词，也不让角色在画内
   复述自己心里的事；旁白只用在时空跳转与情绪落点上，逐段铺满就变成解说而不是小说。
   下游三处同步：逐镜提示词清单标"旁白/字幕（人物不动口型）"而不是"口播"；剪辑单 `[VO]` 字幕按
   浅青处理、声音挂 `配音` 行（可与画面跨切点延续）；视频提示词正文不写 speaks / tells / calls out
   这类会招出人物口型的动词，画外音不由生成模型负责。
   与第 5 条的分工：第 5 条管**人物自己的内心独白**（`[VO]` 或画内对白二选一、剧本层一次定死），
   本条管**叙述者的话**（默认 `[VO]` 旁白）；同一段落两者都有时按本条定旁白，独白句并入或删去，
   不两条声音轨同时说同一件事。
